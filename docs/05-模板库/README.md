# Prompt 模板库

> 复制粘贴即用的 prompt 集合，按场景分类

## 📚 使用说明

每个模板文件里有 N 个完整 prompt，**直接复制粘贴到 Codex 桌面端的输入框就能用**。

按场景分目录：

- [`调研类/`](调研类/) — 竞品分析、行业研究、资料汇总、会议纪要
- [`数据类/`](数据类/) — Excel 清洗、批量处理、表格分析、可视化
- [`效率类/`](效率类/) — 周报生成、月报生成、邮件撰写、翻译
- [`检查类/`](检查类/) — 内容校对、数据校对、格式校对

## 🎯 怎么用模板

1. 选一个跟你的任务最接近的模板
2. 把模板里的 `[方括号占位符]` 替换成你的实际内容
3. 整段粘贴到 Codex 输入框
4. 根据 Codex 第一次的输出，调优 prompt

## 📝 添加新模板

如果你写了一个好用的 prompt，欢迎贡献！

1. 在对应分类目录下新建一个 `.md` 文件
2. 按现有模板的格式写
3. 提 PR

模板格式看 [`TEMPLATE_FORMAT.md`](TEMPLATE_FORMAT.md)。

## ⚠️ 使用提醒

- 所有模板都需要**人工审一遍输出**——Codex 会犯错
- 模板是参考，**根据你的实际情况调整**
- 不要把模板里的 `[占位符]` 直接喂给 Codex——要替换成实际内容
