# 数据校对模板

## 📌 适用场景

Codex 生成的数据报告/表格/分析里，发现数字跟原始数据对不上，需要快速校对。

## 🎯 预期输出

一份校对清单：哪些数字对、哪些数字错、错在哪里、原始数据是多少。

## 📝 完整 Prompt

```
我怀疑你刚才生成的数据报告里有错误。

请按以下步骤帮我校对：

1. 重新读取这个文件夹里所有原始 Excel/CSV 文件
2. 重新计算每个关键指标
3. 跟你刚才生成的报告对比，列出每个数字的差异：
   - 哪个数字在原始数据 vs 报告里
   - 差异百分比
   - 可能是哪个步骤算错了
4. 输出 markdown 校对清单：
   - ✅ 核对正确的（哪些数字一致）
   - ❌ 核对错误的（哪些数字不一致，差异多少）
   - 🤔 不确定的（哪些数字需要回到原始数据再算一次）
5. 如果发现错误，请用原始数据重新生成正确的数字

特别要核对：
- 销售额、用户数、转化率、退款率
- 任何百分比和增长率
- 任何「Top X」类榜单
```

## 💡 调优提示

- **只想校对特定指标**：把「特别要核对」那部分改成你要的指标
- **发现 Codex 编造数据**：在第 1 条前加「请只引用原始数据里有的数字，不要自己推断或编造」
- **想要溯源**：在第 4 条加「每个数字注明出处（哪个文件、哪个单元格）」

## ⚠️ 注意事项

- Codex 可能「狡辩」说「我之前是对的」——坚持要求它**重新读原始文件**
- 如果校对完发现 Codex 系统性地会算错某个指标，**考虑换个 prompt 表达方式**——可能是 prompt 表述有歧义
