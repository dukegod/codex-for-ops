# 月报生成模板

## 📌 适用场景

月底生成一份月度运营报告，比周报更宏观，包含月度趋势、目标完成度、关键项目复盘。

## 🎯 预期输出

一份 markdown 月报，包含：
- 本月概览（3-5 句话总结）
- 关键指标趋势（含 4-5 周的趋势）
- 重点项目进展
- 目标完成度
- 下月规划

## 📝 完整 Prompt

```
读取这个文件夹里所有的 Excel、CSV、Markdown 文件（包含 4-5 周的数据），生成本月运营月报。

要求：

1. **本月概览**（3-5 句话，定性描述本月整体表现）

2. **关键指标月度趋势**：以下 5 个指标的 4-5 周趋势（用 markdown 表格）
   - 销售额
   - 新增用户
   - 活跃用户
   - 转化率
   - 退款率
   
   表格列：指标 / 第 1 周 / 第 2 周 / 第 3 周 / 第 4 周 / 第 5 周 / 月度总计或均值 / 环比上月

3. **重点项目进展**（如果文件夹里有项目相关文档）
   - 每个项目：进展状态、关键成果、遇到的问题
   - 用要点式

4. **目标完成度**
   - 如果文件夹里有月度目标（OKR 文件等），列出每个目标的完成进度
   - 完成度 < 100% 的目标，标注「未达成」并简述原因

5. **下月规划**（3-5 条）

6. **写作风格**：
   - 数据说话，避免形容词
   - 短句为主
   - 月度趋势用表格，描述用要点

7. 输出格式：Markdown，文件保存为 month-report-YYYYMM.md

直接输出，不要让我再追问。
```

## 💡 调优提示

- **想要加入同比去年**：在第 2 条后加「表格再加一列：同比去年」
- **想要 OKR 视角**：在第 4 条加「按 OKR 维度组织：每个 Objective 对应哪些 KR、完成度如何」
- **想要给老板看的版本**：在第 1 条前加「首页加一个『TL;DR』（3 句话摘要，给没时间看全文的人）」

## ⚠️ 注意事项

- 如果月度数据里有重大活动（618、双 11），要在「重点项目进展」里突出
- 月报里的「目标完成度」如果涉及敏感信息（营收目标），用「完成度 95%」这种百分比，**不要写绝对数字**
