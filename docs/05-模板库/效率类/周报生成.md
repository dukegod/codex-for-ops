# 周报生成模板（运营通用版）

## 📌 适用场景

每周/每两周生成一份运营周报，资料分散在多个 Excel、文档、聊天记录里。

## 🎯 预期输出

一个 markdown 格式的周报文件，保存到当前文件夹，包含：
- 本周亮点
- 核心数据回顾
- 问题与风险
- 下周计划
- （可选）数据洞察

## 📝 完整 Prompt

```
读取这个文件夹里所有的 Excel、CSV、Markdown 文件，生成本周运营周报。

要求：
1. 包含以下章节：
   - **本周亮点**（3-5 条，要点式）
   - **数据回顾**：核心指标（销售额、新增用户、活跃用户、转化率、退款率），跟上周对比，标注增减
   - **问题与风险**（至少 3 条，要具体：哪个数据有问题、可能原因是什么）
   - **下周计划**（3-5 条，要点式）

2. 输出格式：Markdown，章节用 ## 二级标题

3. 写作风格：
   - 用数据说话，每个亮点/问题都要带具体数字
   - 不要堆砌形容词（「显著」「大幅」要改成具体百分比）
   - 短句为主，每段不超过 3 行

4. 如果数据里有明显的异常波动（环比 ±20% 以上），请在文末加一个「数据洞察」章节，分析可能原因

5. 文件名：week-report-YYYYMMDD.md（YYYYMMDD 用今天日期）

直接输出报告内容，不要让我再追问。
```

## 🔧 占位符说明

模板里没有占位符，直接复制就能用。Codex 会自动读文件夹里的所有文件并生成报告。

## 💡 调优提示

- **想要更详细的「数据洞察」**：在第 4 条后加「数据洞察要包含：异常指标、可能原因、建议行动」
- **想要更短的报告**：在第 2 条后加「整篇报告控制在 800 字以内」
- **想要 PPT 版本**：在第 5 条后加「另外输出一份 PPT 大纲（每页一个要点）」
- **想要按团队/项目拆分**：在第 1 条前加「如果是销售团队的数据，重点分析销售额；如果是用户运营的数据，重点分析活跃和留存」

## ⚠️ 注意事项

- 周报里的关键数字（销售额、用户数）**自己再算一遍**——Codex 偶尔会算错
- 「问题与风险」里如果有指向具体人/团队的描述，**注意用词**——Codex 可能写得很直接
- 如果数据里有离职员工/已下线产品的数据，Codex 不会自动识别，要在 prompt 里明确说明
