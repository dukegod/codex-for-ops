# Prompt 模板格式规范

每个模板文件用以下格式：

```markdown
# [模板名称]

## 📌 适用场景

[一句话说清楚什么时候用这个模板]

## 🎯 预期输出

[描述你期望 Codex 给你返回什么——文件、文档、数据、图表]

## 📝 完整 Prompt

```
[完整可粘贴的 prompt 文本，包含所有上下文和要求]
```

## 🔧 占位符说明

| 占位符 | 含义 | 示例 |
|-------|------|------|
| `[公司名]` | 你所在公司 | 迷你世界 |
| `[产品名]` | 你负责的产品 | 飞书妙记 |
| `[日期范围]` | 时间段 | 2026-W26 / 2026-06-01 到 2026-06-30 |

## 💡 调优提示

- **如果输出太长**：在 prompt 末尾加「请控制在 X 字以内」
- **如果输出太抽象**：加「请举 3 个具体例子」
- **如果输出偏离重点**：加「请只关注 X，不要涉及 Y」
- **如果 Codex 跑偏**：用「按以下步骤执行」拆解任务

## ⚠️ 注意事项

- [需要注意的点 1]
- [需要注意的点 2]

## 🔗 关联模板

- [其他模板名](其他模板.md)
```

## 文件命名

- 中文 + 简短英文：`周报生成-weekly-report.md`
- 纯中文也行：`周报生成.md`
- 按场景/任务类型命名

## 提交流程

1. 在对应分类目录新建 `.md` 文件
2. 按上面格式填写
3. 在 `README.md` 对应分类的列表里加上文件名
4. 提 PR
