# 5. 你的第一个 Codex 任务：15 分钟上手练习

> 读完前 4 章，你已经知道 Codex 是什么、怎么装、界面长什么样、操作流程是啥。现在，用 15 分钟跑完两个真实任务，把「看懂了」变成「会用了」。

## 🎬 场景故事

小林是刚入职的运营新人，入职第一天老板扔给她一个文件夹：「这里有上周的销售数据和一份会议录音转写稿，帮我出一份周报。」

她打开文件夹看了一眼——一个 CSV 表格、一个 txt 文件，加起来不到 50 行数据。

以前她会花 2 小时手动算数、复制粘贴、写周报。但现在她刚装了 Codex，决定试一试。

**15 分钟后**，她把一份结构化周报发给了老板。

这个章节，我们就用小林手里的那份数据，带你走一遍完整的操作流程。所有示例文件都放在本章的 `examples/` 文件夹里，你可以直接下载使用。

## 🎯 你将学到

- 用 Codex 读取 CSV 数据并生成分析报告
- 用 Codex 把会议录音转写稿整理成结构化纪要
- 体验完整的「准备资料 → 描述任务 → 审结果」流程
- 学会检查 Codex 的输出质量

**预计用时**：15 分钟

## 📋 前置准备

- 已安装 Codex 桌面端（没装的看 [2. 安装与登录](02-安装与登录.md)）
- 已登录 ChatGPT 账号
- 安全模式建议设为「自动编辑」（看 [6. 三种安全模式](06-安全模式.md)）
- 准备好示例文件（下面会教你去哪里拿）

## 🚀 练习一：销售数据分析（8 分钟）

### Step 1：拿到示例文件

本章附带了一份虚构品牌「果味星球」的销售数据：

- 文件：`examples/销售数据-2026W34.csv`
- 内容：8 月 18 日 -24 日，4 款饮品（矿泉水、橙汁、蜜桃乌龙茶、蜂蜜柚子茶）在线上商城和线下门店的每日销售记录
- 共 22 行数据，包含日期、产品名、类别、渠道、数量、单价、销售额

**操作**：把 `examples/` 文件夹里的两个文件复制到你电脑上的一个新文件夹，比如叫 `我的第一次练习`。

> 💡 **小贴士**：CSV 文件可以直接用 Excel 打开，也可以直接喂给 Codex。不需要先转成 `.xlsx`。

### Step 2：创建 Codex 任务

打开 Codex，点左上角 `+ New Task`：

1. **文件夹**：选你刚创建的 `我的第一次练习`
2. **安全模式**：选「自动编辑」
3. **任务描述**：把下面这段 prompt 完整复制进去

```
读取这个文件夹里的 CSV 文件（销售数据），完成以下任务：

1. 汇总每个产品在本周的总销售额和总销量
2. 计算线上商城和线下门店的销售占比
3. 找出本周销售额最高的一天和最低的一天
4. 指出有没有异常数据（比如某天某个产品销量突然翻倍）

输出格式：Markdown 格式，用表格展示汇总数据，然后写 2-3 段分析。
```

点 `Start Task`。

### Step 3：观察 Codex 的工作过程

Codex 跑起来后，你会看到它在做这些事：

```
📁 我的第一次练习/
├─ 📄 销售数据-2026W34.csv    [✓ 已读]
└─ 📄 周会纪要-原始转写.txt    [⏳ 等待中]

💬 Codex：
我读取了销售数据 CSV，发现有 22 条记录，覆盖 4 个产品、2 个销售渠道。
现在开始按产品汇总销售额...
```

**这个阶段你要做的**：看 Codex 的自言自语，确认它理解对了你的数据。如果它说「发现 5 个产品」但你明明只有 4 个，说明它读错了，立刻追加指令纠正。

### Step 4：审核结果

Codex 完成后，检查输出里的这些内容：

- ✅ **数字对不对**：橙汁的总销售额，自己用计算器算一遍（8.5 × 65 + 8.5 × 78 + ...），跟 Codex 的结果对比
- ✅ **占比加起来是不是 100%**：线上 + 线下 = 100%？如果不是，Codex 算错了
- ✅ **异常分析有没有道理**：Codex 说「周四线下橙汁销量翻倍」——你翻一下原始 CSV 看看是不是真的

> ⚠️ **常见坑**：Codex 偶尔会在汇总时把某一列漏掉，或者把「蜜桃乌龙茶」和「蜂蜜柚子茶」搞混。拿到结果后，花 30 秒扫一眼产品名称有没有对上。

如果结果没问题，恭喜你——**第一个任务完成**。

## 🚀 练习二：会议纪要整理（7 分钟）

### Step 1：找到示例文件

还是在同一个 `我的第一次练习` 文件夹里，你已经有一个文件：

- 文件：`examples/周会纪要-原始转写.txt`
- 内容：一场 28 分钟的产品运营周会的原始转写稿，涉及销售回顾、问题讨论、下周安排

### Step 2：在同一个 Codex 任务里追加指令

**不需要新建任务**。在刚才的对话里，直接输入：

```
现在读取这个文件夹里的「周会纪要-原始转写.txt」，帮我整理成结构化会议纪要。

要求：
1. 顶部写清楚会议主题、时间、参会人
2. 按议题分段（销售回顾、问题讨论、下周安排），每个议题下面列出讨论要点和决定事项
3. 文末单独列一个「待办清单」，包含每件事的负责人和截止时间
4. Markdown 格式
```

### Step 3：审核结果

Codex 会再次开始工作。这次重点检查：

- ✅ **参会人有没有遗漏**：原始稿里有 4 个人，Codex 输出里是不是都提到了
- ✅ **待办事项有没有漏**：原始稿里提到的 UTM 标签、A/B 测试、小红书发帖，是不是都在待办清单里
- ✅ **负责人有没有搞混**：UTM 标签是王磊的任务，不是李敏的——如果 Codex 写错了要纠正
- ✅ **有没有编造内容**：如果 Codex 输出了原始稿里没有的议题或数据，那就是幻觉，删掉

> 💡 **小贴士**：如果 Codex 漏掉了一条待办，直接追加一句「你漏了陈琳说的小红书发帖计划，请补上」，不用重新跑整个任务。

## 📝 完整 Prompt 模板

把这两个 prompt 存好，以后做类似任务时直接改改就能用：

**模板 1：数据分析**

```
读取这个文件夹里的 [文件名/文件类型]，完成以下任务：

1. 汇总 [维度A] 的 [指标1] 和 [指标2]
2. 计算 [维度B] 的占比
3. 找出 [指标] 最高和最低的 [时间/类别]
4. 指出有没有异常数据

输出格式：Markdown 格式，用表格展示汇总数据，然后写 2-3 段分析。
```

**模板 2：会议纪要**

```
读取这个文件夹里的会议转写稿，整理成结构化会议纪要。

要求：
1. 顶部：会议主题、时间、参会人
2. 按议题分段，每个议题包含讨论要点和决定事项
3. 文末汇总待办清单（含负责人、截止时间）
4. Markdown 格式
```

更多 prompt 模板看 [Prompt 模板库](../05-模板库/)。

## ⚠️ 常见坑

| 问题 | 原因 | 解决 |
|------|------|------|
| Codex 说「找不到文件」 | 文件夹选错了，或者文件名有中文乱码 | 确认文件夹路径正确；文件名尽量不用特殊符号 |
| 汇总数字对不上 | Codex 漏读了某几行，或者把列头当成了数据 | 让 Codex 把原始数据也列出来，自己核对行数 |
| 会议纪要漏了待办 | 原始稿里的待办藏在口语化表达中（「回头搞一下」） | 追加指令：「请再检查一遍原始稿，把所有提到的后续行动都列出来」 |
| Codex 编造了不存在的内容 | AI 幻觉 | 核对原始文件，找到没有出处的内容直接删掉 |
