## 📋 前置准备

- macOS 12+ 或 Windows 10/11（Windows 11 推荐）
- 至少 4GB 内存（推荐 8GB）
- 2GB 可用磁盘空间
- 稳定的网络（首次启动要联网登录）

## 🚀 操作步骤

### Mac 用户

1. **下载**：
   - 打开 [Codex 官网](https://openai.com/codex/)
   - 点击「Download for macOS」
   - 会下载一个 `.dmg` 文件（大概 200MB）

2. **安装**：
   - 双击 `.dmg` 文件
   - 把 Codex 图标拖到「应用程序」文件夹
   - 等待几秒，安装完成

3. **首次启动**：
   - 在启动台（Launchpad）找到 Codex
   - 双击打开
   - 如果提示「无法打开，因为来自身份不明的开发者」：
     - 系统设置 → 隐私与安全性 → 仍要打开
     - 或者按住 `Control` 键点击 Codex 图标 → 打开

### Windows 用户

1. **下载**：
   - 打开 [Codex 官网](https://openai.com/codex/)
   - 点击「Download for Windows」
   - 会跳转到微软应用商店
   - 也可以直接搜：微软应用商店 → 搜「Codex」

2. **安装**：
   - 在微软应用商店点击「获取」
   - 等待下载安装完成（大概 5 分钟）

3. **首次启动**：
   - 从开始菜单打开 Codex
   - 第一次可能会比较慢（要初始化）

### 登录账号

无论 Mac 还是 Windows，登录流程都一样：

1. 打开 Codex 应用
2. 弹出登录界面：
   ```
   ┌─────────────────────────────┐
   │                             │
   │   Sign in to Codex          │
   │                             │
   │   ┌─────────────────────┐   │
   │   │ Continue with Google│   │
   │   └─────────────────────┘   │
   │   ┌─────────────────────┐   │
   │   │ Continue with       │   │
   │   │ Microsoft           │   │
   │   └─────────────────────┘   │
   │   ┌─────────────────────┐   │
   │   │ Continue with       │   │
   │   │ ChatGPT account     │   │
   │   └─────────────────────┘   │
   │                             │
   │   Or use API Key →          │
   │                             │
   └─────────────────────────────┘
   ```

3. **推荐用 ChatGPT 账号登录**（运营不需要懂 API）：
   - 点击「Continue with ChatGPT account」
   - 浏览器会自动跳转到 ChatGPT 登录页
   - 用你平时用的 ChatGPT 账号登录
   - 回到 Codex 应用，已经登录成功

4. **如果提示手机验证**（第一次登录常见）：
   - 正常流程，输入你的手机号收验证码
   - 验证成功后，未来一段时间内不需要重复验证（10-30 天）

## ⚠️ 登录常见问题

### Q1：提示「账号没有权限」怎么办？
A：说明你登录的账号没有 Codex 访问权限。需要：
- 订阅 ChatGPT Plus / Pro / Team（升级）
- 或者等免费用户开放（OpenAI 有时限期开放给免费用户）

### Q2：提示「该地区不可用」？
A：Codex 在中国大陆不可用直接使用。需要：
- 公司网络代理（合规前提下）
- 或者用海外账号注册

### Q3：Mac 提示「无法打开」？
A：参考上面的步骤，给 Codex 「仍要打开」权限。

### Q4：登录后一直转圈？
A：网络问题。检查：
- VPN / 代理是否稳定
- 系统时间是否准确
- 重启 Codex 重试

### Q5：换电脑怎么迁移？
A：Codex 桌面端**共享 Codex CLI 的配置目录**：
- Mac/Linux：`~/.codex/`
- Windows：`C:\Users\<用户名>\.codex\`

只要把 `auth.json`（认证文件）拷到新电脑，就能直接登录。详细步骤看 [进阶篇 - 项目记忆](docs/03-进阶技巧/03-项目记忆.md)。

## 🎉 第一次跑通测试

登录成功后，先做一个小测试：

1. 在桌面新建一个文件夹，名字叫 `codex-test`
2. 在文件夹里新建一个 `test.txt`，内容随便写点（例：「今天天气不错」）
3. 打开 Codex，点击「+ New Task」
4. 把 `codex-test` 文件夹拖到 Codex 里
5. 在输入框输入：

```
你好！请你读取这个文件夹里的 test.txt 文件，然后告诉我里面写了什么。
```

6. 按 `⏎` 发送

**预期结果**：
- Codex 会列出它看到的文件
- 然后读取 test.txt 并告诉你内容

如果能看到这个结果，恭喜你，**Codex 桌面端就跑通了**。
