# 3. 第一次启动 & 界面导览

> 认识 Codex 桌面端的界面，运营专用版

## 🎬 场景故事

小张装好 Codex 后打开一看：「这界面跟 IDE 一样，左边任务列表、右边 diff、底部 terminal……」他有点懵：「我又不是程序员，这界面我能看懂吗？」

**别担心。这篇就是用运营的视角，把界面每个部分讲清楚**——你不需要懂开发也能用。

## 🎯 你将学到

- Codex 桌面端界面每个部分是干什么的
- 哪些是运营会用的、哪些是程序员用的
- 怎么新建你的第一个任务
- 怎么阅读任务结果

## 🚀 打开 Codex

打开后你会看到主界面：

```
┌─────────────────────────────────────────────────────┐
│  ≡  Codex                          [+ New Task] [⚙] │
├─────────────┬───────────────────────────────────────┤
│             │                                       │
│  📋 Tasks   │  Hi! I'm Codex.                       │
│             │  Ask me to read your files, generate   │
│  ▸ 周报生成  │  reports, or do data analysis.       │
│    (运行中)  │                                       │
│             │  ┌─────────────────────────────────┐ │
│  ▸ 竞品分析  │  │ Ask Codex to do anything...     │ │
│    (已完成)  │  │                          [📎] [⏎]│ │
│             │  └─────────────────────────────────┘ │
│  ▸ 数据清洗  │                                       │
│    (已完成)  │                                       │
│             │                                       │
│  [+ New]    │                                       │
│             │                                       │
├─────────────┴───────────────────────────────────────┤
│  [建议模式]  当前模型: GPT-5  剩余配额: 92%  🟢       │
└─────────────────────────────────────────────────────┘
```

每个区域的作用：

### 顶部菜单栏
- **`≡`**：左侧栏开关（点开/收起任务列表）
- **`+ New Task`**：新建任务（**最重要的按钮**）
- **`⚙`**：设置（切换安全模式、改语言、看配额）

### 左侧任务栏（Tasks）
- 这里列了你所有的任务
- 每个任务有 3 个状态：等待中 / 运行中 / 已完成
- 点任意一个任务可以查看历史结果
- **`+ New`**：在底部，也可以新建任务

### 主对话区
- 顶部：欢迎语（首次打开时）
- 中间：历史对话内容（滚动浏览）
- 底部输入框：在这里输入你想让 Codex 做的事
- **`📎`**：附件按钮（上传图片、文件）
- **`⏎`**：发送（按回车键也可以）

### 底部状态栏
- **安全模式**：当前是「建议模式」/「自动编辑」/「全自动」（重要！详细看 [5. 安全模式](05-安全模式.md)）
- **当前模型**：GPT-5 / GPT-4 等
- **剩余配额**：你的 Plus/Pro 账号 5 小时窗口还剩多少额度

## 👀 你不需要管的部分

Codex 界面有些部分是给程序员用的，**运营可以完全忽略**：

- **Worktree**：左边每个任务下的「工作分支」——给程序员用的，运营不用管
- **Diff 视图**：Codex 改文件时显示的「改了什么」——运营只需要看 Codex 总结给你的话
- **Terminal / Shell**：底部的命令行窗口——运营不需要碰
- **PR / Commit**：跟 Git 相关的操作——运营不需要碰

如果你看到这些，**直接忽略它们，看 Codex 给你写的文字总结就行**。

## 🚀 新建你的第一个任务

点击 **`+ New Task`** 按钮，你会看到这个对话框：

```
┌─────────────────────────────────────────────────────┐
│  New Task                                        [×] │
├─────────────────────────────────────────────────────┤
│                                                     │
│  📁 Folder:    [ 选择文件夹...]                     │
│                                                     │
│  🤖 Agent:     [Default Agent ▼]                    │
│                                                     │
│  ✏️ Description:                                     │
│  ┌─────────────────────────────────────────────────┐│
│  │                                                 ││
│  │  描述你想让 Codex 做什么...                      ││
│  │                                                 ││
│  │                                                 ││
│  └─────────────────────────────────────────────────┘│
│                                                     │
│                            [Cancel]  [Start Task]   │
└─────────────────────────────────────────────────────┘
```

填写步骤：

### Step 1：选文件夹（**关键！**）

点击「**选择文件夹**」，选你这次任务相关的资料文件夹。

> 💡 **小贴士**：把这次任务要用的资料**全部放进同一个文件夹**。Codex 默认只读你授权的文件夹，所以提前归类好能让 Codex 看到所有需要的资料。

举例：
- 做周报 → 把本周所有 Excel、文档、截图放进「`2026-W26周报`」文件夹
- 竞品分析 → 把 3 家竞品的资料放进「`竞品分析-Q2`」文件夹
- 会议纪要 → 把会议转写稿放进「`2026-06-30产品评审会`」文件夹

### Step 2：选 Agent（默认即可）

一般保持「**Default Agent**」。如果要深入用，可以看 [进阶篇 - 多 Agent 并行](docs/03-进阶技巧/04-多agent并行.md)。

### Step 3：填任务描述

**这是最关键的一步**——你描述得越清楚，Codex 干得越好。

好的描述 vs 不好的描述：

| ❌ 不好的描述 | ✅ 好的描述 |
|------------|----------|
| 「帮我做个周报」 | 「读取这个文件夹里的 3 个 Excel（销售数据、用户反馈、活动数据），按本周亮点、数据回顾、问题与风险、下周计划 4 个章节生成一份周报，输出 markdown 格式」 |
| 「分析一下竞品」 | 「读取这个文件夹里 3 家竞品的官方介绍 PDF，提取：产品名、目标用户、核心功能、定价、近期动态，生成对比表（markdown 格式）」 |
| 「整理一下资料」 | 「这个文件夹里有 10 份会议纪要的 md 文件，按时间顺序合并，去掉重复段落，输出一份完整汇总」 |

**模板：**

```
读取这个文件夹里的 [资料类型]，帮我做 [具体任务]。

要求：
1. [要求 1]
2. [要求 2]
3. 输出格式：[格式]
```

更多完整 prompt 模板看 [模板库](docs/05-模板库/)。

### Step 4：点 Start Task

Codex 开始跑任务。你会看到：

```
┌─────────────────────────────────────────────────────┐
│  📋 Task: 周报生成                                  │
│                                                     │
│  ⏳ Running...                                      │
│                                                     │
│  📁 2026-W26周报/                                   │
│  ├─ 📄 销售数据.xlsx        [读取中...]              │
│  ├─ 📄 用户反馈.xlsx        [读取中...]              │
│  └─ 📄 活动数据.csv         [等待...]               │
│                                                     │
│  💬 Codex:                                          │
│  正在分析销售数据...                                 │
│                                                     │
│  ┌─────────────────────────────────────────────────┐│
│  │ Ask follow-up...                  [⏎]           ││
│  └─────────────────────────────────────────────────┘│
│                                                     │
│                            [Stop]  [Continue →]     │
└─────────────────────────────────────────────────────┘
```

你会看到 Codex 实时在做什么：
- 它读了哪些文件
- 它在想什么（右上角「💬 Codex」区域）
- 进度（百分比或者状态）

## ⏸️ 任务运行中的操作

Codex 跑任务时你可以：

- **看过程**：实时看 Codex 在做什么
- **追加指令**：在底部输入框输入「等等，补充一下，还要加 xxx 字段」
- **暂停**：点 [Stop] 按钮
- **继续**：点 [Continue →]（如果是多步任务）

## ✅ 任务完成后

任务跑完，你会看到：

```
┌─────────────────────────────────────────────────────┐
│  📋 Task: 周报生成  ✅ 完成                         │
│                                                     │
│  💬 Codex:                                          │
│  已生成周报，输出到 📄 week26-report.md             │
│                                                     │
│  📁 2026-W26周报/                                   │
│  ├─ 📄 销售数据.xlsx                                │
│  ├─ 📄 用户反馈.xlsx                                │
│  ├─ 📄 活动数据.csv                                 │
│  └─ 📄 week26-report.md        [新建]              │
│                                                     │
│  [📋 复制]  [📁 打开]  [🔄 重新生成]                │
└─────────────────────────────────────────────────────┘
```

几个关键操作：

- **`📋 复制`**：把 Codex 的输出文字复制到剪贴板
- **`📁 打开`**：打开 Codex 生成的文件（如果有生成文件）
- **`🔄 重新生成`**：如果结果不满意，让 Codex 重做

## 🎯 你刚才做的事（一句话总结）

1. 打开 Codex → 看主界面
2. 点 `+ New Task` → 选文件夹 → 填任务描述
3. 等 Codex 跑完
4. 看结果

**这就是 Codex 桌面端 80% 的用法了。**
