# 6. 三种安全模式：你能在什么范围内让 Codex 干活

> 搞清楚 Codex 能做什么、不能做什么，运营用得不慌

## 🎬 场景故事

小陈第一次用 Codex，选了「Full-Auto 全自动」模式，结果：
- Codex 把他授权的文件夹里 30% 的文件改了名
- 跑了一个他不知道的脚本
- 生成了一堆他没要求的临时文件

**运营第一次用 Codex，最容易犯的错就是「权限开太大」**。

## 🎯 你将学到

- Codex 的 3 种安全模式分别是啥
- 运营该用哪种模式
- 怎么切换安全模式
- 怎么只授权 Codex 访问特定文件夹
- 怎么撤销授权

## 📋 一句话总结

| 模式 | Codex 能干啥 | 运营推荐度 |
|------|------------|----------|
| 🟢 **建议模式（Suggest）** | 只给方案、不动手 | ⭐⭐⭐⭐⭐ **新手推荐** |
| 🟡 **自动编辑（Auto-Edit）** | 自动改文件，但跑命令要你确认 | ⭐⭐⭐⭐ **日常推荐** |
| 🔴 **全自动（Full-Auto）** | 全自动跑，沙箱隔离 | ⭐⭐ **只在信任场景用** |

## 🟢 建议模式（Suggest）—— 新手推荐

### 是什么

Codex **只给方案**，不直接动手。你看到方案后，一步步批准/拒绝。

### 工作流程

```
你：帮我整理这个文件夹里的 Excel，生成周报
       ↓
Codex：我打算这样做：
  1. 读取 销售数据.xlsx
  2. 读取 用户反馈.xlsx
  3. 生成 week26-report.md
       ↓
   [Approve]  [Reject]  [修改方案]
       ↓
你：批准
       ↓
Codex：开始执行（每一步还会让你确认）
```

### 适合场景

- ✅ 第一次用 Codex
- ✅ 处理重要数据
- ✅ 不确定 Codex 会做什么
- ✅ 涉及敏感信息（虽然建议模式还是建议先脱敏）

### 不适合场景

- ❌ 大批量重复任务（每次都确认太累）
- ❌ 跑定时任务（没人在场确认）

## 🟡 自动编辑（Auto-Edit）—— 日常推荐

### 是什么

Codex **自动改你授权的文件**，但跑命令（运行脚本、执行操作）需要你确认。

### 工作流程

```
你：帮我整理这个文件夹
       ↓
Codex：自动读文件、自动生成新文件、自动改文件
       ↓
Codex：我要执行这条命令 [运行 Python 脚本]，批准吗？
       ↓
   [Approve]  [Reject]
       ↓
你：批准
       ↓
Codex：继续
```

### 适合场景

- ✅ **大多数运营日常工作**——周报、月报、数据清洗
- ✅ 已经信任 Codex 的输出质量
- ✅ 任务包含脚本执行（Excel 处理、批量重命名）

### 不适合场景

- ❌ 完全不熟悉 Codex（先在 Suggest 模式练手）
- ❌ 处理从未见过的文件类型

## 🔴 全自动（Full-Auto）—— 高风险

### 是什么

Codex **全自动执行**，包括改文件、跑命令、生成文件。你只需要等结果。

但 Codex 仍然在「**沙箱**」里跑——不能访问你授权文件夹之外的东西，不能联网（除非你额外允许）。

### 工作流程

```
你：Full-Auto 模式，帮我整理这个文件夹
       ↓
Codex：[自动跑，没问你任何问题]
       ↓
[5 分钟后] Codex：完成，生成了 X 个文件
```

### 适合场景

- ✅ **定时任务**（自动化跑，没人盯着）
- ✅ 已经反复跑过、验证过的任务
- ✅ 批量可重复的任务（100 张照片重命名）

### 不适合场景

- 🚨 **第一次跑的任务**——不知道结果会怎样
- 🚨 **敏感数据**——即使沙箱隔离，也不要冒这个险
- 🚨 **不可逆操作**——比如「删除 100 个文件」（虽然 Codex 会先确认，但全自动下风险大）

## 🚀 怎么切换安全模式

### 方法 1：底部状态栏切换（最快）

看 Codex 主界面底部：

```
[建议模式]  当前模型: GPT-5  剩余配额: 92%  🟢
```

点 `[建议模式]` 这个下拉：

```
┌─────────────────┐
│  ○ 建议模式      │
│  ● 自动编辑     │  ← 选中这个（日常推荐）
│  ○ 全自动       │
└─────────────────┘
```

选好后立即生效。

### 方法 2：新建任务时切换

新建任务时，在弹窗底部有安全模式选择：

```
┌─────────────────────────────────────────────────────┐
│  New Task                                        [×] │
├─────────────────────────────────────────────────────┤
│  📁 Folder:    [...]                                │
│  🤖 Agent:     [Default]                            │
│  ✏️ Description:                                     │
│  ┌─────────────────────────────────────────────────┐│
│  │ ...                                             ││
│  └─────────────────────────────────────────────────┘│
│                                                     │
│  🛡️ Safety Mode: [🟢 建议模式] [🟡 自动编辑] [🔴 全自动]│
│                                                     │
│                            [Cancel]  [Start Task]   │
└─────────────────────────────────────────────────────┘
```

选好再点 Start Task。

### 方法 3：设置里改默认

点右上角 `⚙` 设置 → 「Default Safety Mode」 → 选一个。

**给运营的建议**：
- 默认设为 **🟡 自动编辑**（日常推荐）
- 重要/敏感任务临时切到 🟢 建议模式
- 定时任务用 🔴 全自动

## 📁 文件夹授权：让 Codex 只能访问你授权的内容

### 为什么重要

Codex 默认**只能读写你明确授权的文件夹**。这意味着：

- 你只授权了 `2026-W26周报/`，Codex 就读不到其他文件夹
- 你撤销授权，Codex 就再也不能访问了

**这是 Codex 最关键的安全设计**——避免 Codex 误删/误改你电脑上的其他文件。

### 怎么授权文件夹

新建任务时：
1. 点「选择文件夹」
2. 选你这次任务相关的文件夹
3. **只选需要的，别把整个桌面/下载文件夹给授权了**

```
❌ 不要：
   授权 整个 Downloads 文件夹（里面有几百个乱七八糟的东西）

✅ 应该：
   授权 2026-W26周报/ 这个具体文件夹
```

### 怎么查看授权了哪些文件夹

点 `⚙` 设置 → 「Authorized Folders」：

```
┌─────────────────────────────────────┐
│  Authorized Folders                 │
├─────────────────────────────────────┤
│  📁 2026-W26周报/      [已授权] [撤销]│
│  📁 竞品分析-2026Q2/   [已授权] [撤销]│
│  📁 会议-2026-06-30/   [已授权] [撤销]│
└─────────────────────────────────────┘
```

### 怎么撤销授权

两种方式：

**方式 1**：在上面的设置界面点 [撤销]

**方式 2**：让 Codex 自己撤销（适合不想手动找的情况）

```
列出我目前授权给 Codex 的所有文件夹，然后帮我撤销「2026-W26周报/」这个授权。
```

## ⚠️ 重要安全原则

### 原则 1：永远不要授权根目录/整个桌面

```
❌ 授权 /Users/你的用户名/Desktop/     （整个桌面）
❌ 授权 C:\Users\你的用户名\Desktop\   （整个桌面）
❌ 授权 ~/Downloads/                   （整个下载文件夹）

✅ 授权 /Users/你的用户名/Documents/工作/2026-W26周报/
✅ 授权 C:\Users\你的用户名\Documents\Work\2026-W26周报\
```

### 原则 2：定期清理授权

每季度清理一次「Authorized Folders」，撤销不再需要的授权。

### 原则 3：重要数据先备份再让 Codex 处理

Codex 误操作概率低，但**不为零**。重要文件夹跑任务前：

```
cp -r 2026-W26周报/ 2026-W26周报-backup/
```

或者用 Time Machine（Mac）/ 文件历史记录（Windows）——这俩是系统级备份。

### 原则 4：跑重要任务前先小范围测试

第一次用 Codex 处理某个新类型任务：

```
1. 复制 1-2 个样本文件到测试文件夹
2. 在测试文件夹跑 Codex，确认输出满意
3. 再用真实文件夹跑
```

## 🚨 紧急情况：Codex 跑飞了怎么办？

如果 Codex 在跑任务时做了不该做的事：

### 立即反应

1. **点 [Stop] 按钮** —— 立即停止当前任务
2. **在输入框输入**：
   ```
   立即停止。撤销刚才所有操作。给我列出刚才你改过/删除/创建的所有文件。
   ```
3. **去检查 Codex 实际做了什么** —— 看 Codex 的输出和它生成的文件
4. **如果有损失**：
   - 从备份恢复
   - 用 git 撤销（如果文件夹是 git 仓库）
   - 找 IT 帮忙

### 预防

- 永远不要在 🔴 全自动模式下跑陌生任务
- 永远不要授权根目录
- 永远先备份
