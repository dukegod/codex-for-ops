# 10. 桌面端新功能速通（2026 GA 版）

> 已经会基础操作了？花 30 分钟把这 5 个新功能过一遍，立刻起飞

## 🎬 场景故事

周五下午 4 点，市场部小王刚把本周用户反馈 Excel 整理完，老板又来催：

> "把这份数据做成**可视化页面**，能发给客户看的那种。再把本周的销售异常做个**5 分钟简报**。我 5:30 开会要用。"

小王脑子里飘过几个念头：
- 数据可视化页面 → 找设计部 → 排期下周
- 简报 → 写 1 小时 → 必加班

但他突然想起来——Codex 桌面端这周刚更新，听说有"**直接生成网站**"和"**把屏幕直接扔给 Codex**"这种功能。

**30 分钟后**，他把可视化页面链接甩到群里，把简报 PDF 也发给了老板。下班。

## 🎯 你将学到

- 用 **Appshots** 一键把任何窗口扔给 Codex
- 用 **Sites** 5 分钟生成可发布的数据看板
- 用 **/goal** 让 Codex 跑几天的任务不用盯着
- 用 **Computer Use** 远程遥控办公室的 Mac
- 用 **Skills** 把重复工作流打包成 `/` 一键调用
- 用 **Annotate Mode** 在网页上"指哪改哪"

**全程不写代码**。

## 📋 前置准备

- Codex 桌面端 **2026 年 6 月 GA 版**（点 Settings → Updates 确认）
- ChatGPT 账号（Plus / Pro 体验最佳）
- 准备一个测试项目文件夹（`~/test-codex/`）
- **在文件夹根目录建一个 `AGENTS.md`**——这是立规矩的第一步

`AGENTS.md` 模板（直接复制）：

```markdown
# AGENTS.md
## 基本规则
- 修改前先看完整文件，不要猜结构
- 完成任务后运行验证命令（如果有）
- 不要新增未经确认的依赖

## 不要做
- 不要把客户的真实姓名、电话、地址写进任何生成内容
- 不要修改本规则文件
```

## 5 个新功能，按"爽感"排序

### ① Appshots — 报错窗口、截图直接扔

**场景**：看到任何窗口（报错、聊天、设计稿），双击 ⌘ 抓进 Codex。

**用法**：
1. 焦点放到目标窗口
2. **双击 ⌘**（默认快捷键，可在 Settings → Shortcuts 改）
3. 窗口内容自动进对话

**运营实战**：客户在微信甩了张截图问"这是啥意思"，你双 ⌘ 抓进来，Codex 直接解读，比你自己读图快 10 倍。

### ② Sites — 5 分钟生成可发布的网页

**场景**：数据看板、活动页、内部工具——一句话生成 + 一键发布。

**用法**：
1. 左侧栏点 **Sites**（如果没看到，版本太旧）
2. 输入 prompt，下面这份直接抄：

```
做一个用户反馈数据看板：
- 顶部 4 个 KPI 卡片：总反馈数、本周新增、已处理率、平均响应时长
- 中间用柱状图展示本周每日反馈量
- 下方分两栏：左侧 Top 5 反馈类型，右侧最近 10 条反馈摘要
- 风格：浅色底 + 蓝绿主色，参考 linear.app 的简洁感
- 数据来源：读取当前文件夹里的 "本周反馈.csv"
```

3. Codex 自动写代码 → 预览 → 部署，给你一个可访问的 URL

**国内运营注意**：Sites 默认走 OpenAI CDN，国内访问偶尔慢。生成后右键"下载 HTML"自己部署到腾讯云 / 阿里云，更稳。

### ③ /goal — 长期任务挂着跑

**场景**：多步、跨天的复杂任务（比如"把这季度所有周报整合成半年报"）。

**开启方式**（终端里跑一次）：

```bash
codex features enable goals
```

**用法**：在 Codex 对话里以 `/goal` 开头说：

```
/goal 把当前文件夹里 13 个周报整合成 H1 半年报：
- 合并数据（销售额、新增、活跃、转化）
- 按月分组，生成 6 个趋势图
- 找出 3 个最大增长点 + 3 个最大风险点
- 每周单独一个章节
- 每完成一个月跟我说一声，我看下没问题再继续
```

Codex 会自己跑，期间你随时可以 **暂停** / **Fork** / **查看进度**。

### ④ Computer Use — 远程遥控办公室的 Mac

**场景**：下班路上用手机指挥办公室 Mac 干活。

**前提**（少一个都不行）：
- Mac 装 Codex 桌面端，**保持运行**（最新版支持锁屏后台跑）
- macOS 15+

**设置**：
1. Mac 端：Codex → Settings → **Remote Control** → 打开
2. 手机端：ChatGPT App → 选 Codex → 选你的 Mac
3. 发指令，Codex 截屏给你看进度

**运营实战**：通勤路上让 Codex 帮你整理 30 个客户反馈表，回家了直接看结果。

### ⑤ Skills — 把重复工作流打包

**场景**：每周五都要做的事（比如"周报"），打包成 `/weekly` 一键调用。

**用法**：
1. Codex 对话里输入 `/`，选 `+ New Skill`
2. 按模板填：

```yaml
name: 运营周报
description: 读取飞书周报模板 + 5 个核心指标 Excel，生成周报
trigger: /weekly
inputs:
  - 本周日期范围
steps:
  - 读取飞书"运营周报模板"（MCP）
  - 拉取本周核心 5 指标
  - 对比上周数据
  - 输出 markdown
  - 自动存档到 /周报归档/2026/
```

3. 下次直接 `/weekly 2026-07-28 ~ 2026-08-03` 完事

**已有模板**：[周报生成 Skill 模板](../06-发布社区/templates/weekly-report-skill.md) 可以直接抄。

## 30 分钟演示剧本

想一次性把所有功能过一遍，照这个跑：

```
[00:00] 建 ~/test-codex/ 文件夹 + 放 AGENTS.md
[02:00] 打开 Codex，选这个文件夹
[05:00] 输入："用 Sites 给我做一个咖啡馆首页"
[15:00] 生成完 → 切到 Annotate Mode → 点标题改成"Starbucks 风格"
[20:00] 打开任意报错窗口 → 双 ⌘ → 问"这是啥错"
[25:00] 输入 /goal：把这个咖啡馆页面改成支持暗黑模式
[30:00] 用手机 ChatGPT App 试试能不能接管 Mac
```

跑完一遍，你就知道哪些功能对你的工作最有用。

## ⚠️ 常见坑

**坑 1：版本太旧看不到 Sites / Annotate Mode**
- 症状：左侧栏没有 Sites 入口、Annotate Mode 按钮灰色
- 解决：Settings → Updates → 升到 26.6.x 之后版本

**坑 2：Mac 不在 15 没法用 Computer Use**
- 症状：Remote Control 按钮找不到
- 解决：升 macOS 15+，或者用手机控制别人升了 15 的 Mac

**坑 3：AGENTS.md 没建就开始用**
- 症状：Codex 上来就乱删文件、新增一堆你没要的依赖
- 解决：**永远先建 AGENTS.md 再用**——这是你给 Codex 立规矩的唯一机会

**坑 4：把客户隐私数据喂给 Sites**
- 症状：客户姓名、手机号进了生成的网页 → 公网可访问 = 泄露
- 解决：见 [数据安全](../04-安全红线/01-数据安全.md)，AGENTS.md 里务必加脱敏规则

**坑 5：/goal 设了任务就不管了**
- 症状：跑了 2 天才去看，结果中间方向就歪了
- 解决：每个 /goal 任务都要求"每完成一个子任务跟我说一声"
