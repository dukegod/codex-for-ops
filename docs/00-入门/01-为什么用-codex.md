# 1. Codex 是什么 & 能帮运营做什么

> 30 秒搞懂 Codex 桌面端到底是个啥

## 🎬 场景故事

小王是市场调研组的同事，每周五下午都要做一件事：把本周的活动数据、销售周报、用户反馈汇总成一份周报。这活儿他干了 3 年，每次都要：
- 打开 5 个 Excel，手动合并
- 复制粘贴到飞书文档
- 改格式、调字号、配图
- 至少 3 小时

最近他开始用 Codex 桌面端。同样一份周报，现在他只需要：
1. 把 5 个 Excel 拖进一个文件夹
2. 在 Codex 里输入一句「帮我把这一周的周报生成出来」
3. 喝杯咖啡，10 分钟后回来审一遍

**3 小时 → 30 分钟**。

- Codex 桌面端到底是什么

- 它的核心能力边界

## 📋 一句话定义

**Codex 桌面端 = 装在你电脑上的 AI 智能体，能读你电脑里的文件、整理资料、生成报告、处理数据，而且能跑定时任务。**

跟 ChatGPT 网页版的区别是：
- **ChatGPT 网页版**：你给它文字，它给你文字
- **Codex 桌面端**：你给它一个文件夹 + 一个任务，它直接读你的文件、生成新文件、改你的数据

## ✅ Codex 桌面端能帮运营做的事

### 📊 调研岗
- 竞品分析：让 Codex 读 5 家竞品的资料，自动生成对比表
- 行业研究：让 Codex 读一堆行业报告，提炼核心观点
- 资料汇总：把散落在飞书、邮件、本地的资料整理成结构化文档
- 会议纪要：让 Codex 把会议录音转写稿整理成结构化纪要

### 📈 数据岗
- Excel 清洗：批量去除空行、统一格式、修复格式错误
- 批量处理：批量重命名 200 张照片、按规则改文件名
- 表格分析：让 Codex 跑描述统计、找异常点、出洞察
- 图表生成：让 Codex 直接生成可用的图（折线、柱状、热力图）

### 📝 内容岗（如果团队有）
- 多平台改写：一篇公众号 → 小红书 / 知乎 / 微博
- 长文摘要：把 50 页白皮书压成 500 字摘要
- 营销话术：A/B 测试多个版本的话术

### 🎯 增长岗
- 用户反馈分类：把 1000 条用户评论自动分类（好评/差评/功能请求/Bug）
- 活动复盘：让 Codex 读活动数据 + 用户反馈，生成复盘报告
- 调研报告：让 Codex 读问卷数据，自动出调研报告初稿

## ❌ Codex 桌面端**不适合**做的事

为了让团队对 Codex 有合理预期，**这些场景不适合用 Codex**：

- 🚨 **客户隐私数据**：未脱敏的用户数据、客户手机号、银行卡号——见 [数据安全](../04-安全红线/01-数据安全.md)
- 🚨 **未公开的财务/战略信息**：薪资、并购、人事变动、未发布的产品 roadmap
- ❌ **需要 100% 准确的数字**：Codex 是 AI，会算错，关键数字必须人工核实
- ❌ **实时性要求极高的数据**：股价、实时交易、即时通讯——Codex 不是实时系统
- ❌ **高度创意的主观判断**：品牌定位、广告创意——Codex 能给候选但不能替决策
- ❌ **法律/医疗/金融的专业决策**：Codex 是工具，不是专业人士

## 🤔 跟其他 AI 工具比，Codex 桌面端有啥不一样

| 工具 | 适合做什么 | 不适合做什么 |
|------|----------|------------|
| **ChatGPT 网页版** | 聊天、写作、问答、学习 | 批量处理文件、跑任务、定时执行 |
| **Claude 网页版** | 同上，长文本更友好 | 同上 |
| **Cursor / Trae** | 写代码 | 运营日常 |
| **Notion AI** | Notion 文档内的 AI | 跨工具、本地文件 |
| **Coze / Dify** | 搭自动化流程 | 单次任务、轻度使用 |
| **Codex 桌面端** | ✅ 读本地文件 + 整理 + 跑任务 + 定时 | 实时性、100% 准确性 |

简单说：**运营要处理「电脑上那堆乱七八糟的文件」时，Codex 桌面端是最对口的工具**。

## 🎯 核心能力速览

Codex 桌面端有几个关键能力，按运营的实际使用频率排序：

### 1. 读文件 + 整理（90% 的运营场景）
让 Codex 读你的文件夹 → 它给你结构化输出。这是运营最常用的功能。

### 2. 批量处理（高频）
让 Codex 批量改文件名、改格式、抽信息。100 张照片、50 份 PDF 都不在话下。

### 3. Skills（进阶）
把常用的 prompt 存成「一键按钮」，下次直接点。适合每周都做的任务（周报生成、竞品监控）。

### 4. 自动化任务（进阶）
让 Codex 定时跑某个任务，比如每周一早 9 点自动生成上周周报。

### 5. 多 Agent 并行（高阶）
同时跑多个 Agent，每个 Agent 处理一个独立任务，效率翻 N 倍。

### 6. AGENTS.md（团队协作）
在工作文件夹根目录放一份「项目说明书」，Codex 每次都会读，团队成员共享。
