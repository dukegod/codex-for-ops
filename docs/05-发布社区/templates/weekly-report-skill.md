# 运营周报自动生成 Skill

## 使用场景

- 每周一上午生成上周运营周报
- 每月初生成上月运营月报
- 季度汇报需要把多周数据整合
- 给老板做临时运营简报

## 不适用场景

- ❌ 需要精确到个位数的财务报告（Codex 可能算错）
- ❌ 需要法律/合规审核的对外披露
- ❌ 公司内部未公开的产品/财务数据
- ❌ 完全没有数据的周（比如刚启动的新业务）

## 输入要求

### 必需资料

在指定文件夹里放：

```
weekly-report-input/
├── 销售数据.xlsx        # 或 CSV
├── 用户数据.xlsx
├── 活动数据.csv
└── 本周重要事项.md      # 任何文本格式的本周要点
```

### 可选资料

- 上周周报（用于环比对比）
- OKR 文档（用于目标完成度评估）
- 用户反馈原始数据

## 完整步骤

### Step 1：准备资料

把本周所有相关数据放进一个文件夹，命名建议带日期：`weekly-report-2026-W26`。

### Step 2：新建 Codex 任务

1. 打开 Codex 桌面端
2. 点 + New Task
3. 选刚才的资料文件夹
4. 安全模式：🟡 自动编辑
5. 粘贴下面的「完整 Prompt」
6. 点 Start Task

### Step 3：等 Codex 跑

约 10-20 分钟，Codex 会读所有文件并生成周报。

### Step 4：审阅 + 微调

打开生成的 `week-report-YYYYMMDD.md`：
- 核对关键数字（销售额、用户数等）
- 调整不符合品牌调性的措辞
- 补充 Codex 漏掉的洞察

## 完整 Prompt

```
读取这个文件夹里所有的 Excel/CSV/Markdown 文件，
生成本周运营周报。

要求：

1. 包含以下章节：
   - **本周亮点**（3-5 条，要点式）
   - **数据回顾**：核心指标（销售额、新增用户、活跃用户、转化率、退款率），
     跟上周对比，标注增减
   - **问题与风险**（至少 3 条，要具体）
   - **下周计划**（3-5 条，要点式）

2. 输出格式：Markdown，章节用 ## 二级标题

3. 写作风格：
   - 用数据说话，每个亮点/问题都要带具体数字
   - 不要堆砌形容词（「显著」「大幅」要改成具体百分比）
   - 短句为主，每段不超过 3 行

4. 如果数据里有明显的异常波动（环比 ±20% 以上），
   在文末加一个「数据洞察」章节，分析可能原因

5. 文件名：week-report-YYYYMMDD.md（YYYYMMDD 用今天日期）

6. 直接输出报告内容，不要让我再追问
```

## 注意事项

### 🚨 数据准确

- 所有数字必须自己再算一遍
- 引用必须能溯源到原始 Excel
- Codex 可能漏掉字段，检查 Excel 里的所有列是否都用上了

### 🚨 敏感信息

- 不要喂客户隐私数据
- 不要写未公开的财务数字（用百分比，不用绝对数）
- 公司内部代号要做脱敏

### ⚠️ 风格统一

- 用 markdown，不用富文本
- 表格用 markdown 格式
- 数字格式统一：万 / % / 保留 2 位小数

### ⚠️ 常见坑

1. **数据缺失**：如果 Excel 缺关键字段，Codex 会瞎编
   - 解决：prompt 里明确「如果缺数据，标『待补』而不是瞎填」
2. **指标定义混乱**：销售额是含税还是不含税？
   - 解决：AGENTS.md 里写清楚每个指标的定义
3. **跨周数据混淆**：上周数据放错文件夹
   - 解决：每次新建独立文件夹，命名带日期
4. **格式不一致**：Excel 列名不一样（中英文、缩写）
   - 解决：跑 Skill 前先做一次 Excel 清洗
5. **Codex 算错**：百分比算错、累计求和漏行
   - 解决：人工核算关键数字
