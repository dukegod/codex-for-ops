# 竞品对比分析 Skill

## 使用场景

- 周一上午做本周竞品监控
- 月底做季度竞品分析
- 新产品发布前的竞品 baseline
- 给老板做临时竞品简报
- 投资人沟通前的竞品准备

## 不适用场景

- ❌ 需要精确数字（Codex 可能算错）
- ❌ 需要法律/合规审核的对外报告
- ❌ 公司内部未公开的产品/财务信息
- ❌ 涉及商业机密（爬竞品的内部数据）

## 输入要求

### 必需资料

在指定文件夹里放 3-5 家竞品的最新资料：

```
competitor-input/
├── competitor-A-2026-06-29.pdf
├── competitor-B-2026-06-29.pdf
├── competitor-C-2026-06-29.md
└── competitor-D-2026-06-29.html
```

**支持的格式**：
- PDF（产品介绍、白皮书、新闻稿）
- Markdown / TXT（人工整理的笔记）
- 网页截图（PNG / JPG）
- Word / Excel

### 可选资料

- 上周/上月的竞品周报（用于趋势对比）
- 公司内部关注点清单（让 Codex 重点分析某些维度）

## 完整步骤

### Step 1：准备资料

把本周竞品资料放进一个文件夹，命名带日期：`competitor-2026-W26`。

### Step 2：新建 Codex 任务

1. 打开 Codex 桌面端
2. + New Task
3. 选资料文件夹
4. 安全模式：🟡 自动编辑
5. 粘贴下面的「完整 Prompt」
6. 点 Start Task

### Step 3：等 Codex 跑

约 15-25 分钟，Codex 会：
1. 读所有竞品资料
2. 提取关键信息
3. 生成对比表
4. 输出 markdown 报告

### Step 4：审阅 + 微调

- 核对关键信息（特别是产品功能描述）
- 补充 Codex 漏掉的对比维度
- 加入你的判断（Codex 是中立的，但报告需要「我们的视角」）

## 完整 Prompt

```
读取这个文件夹里所有竞品资料（PDF/MD/HTML/截图），
生成本周竞品对比分析报告。

要求：

1. 提取每个竞品的以下信息（如果资料里有）：
   - 公司名 / 产品名
   - 本周核心更新（产品功能、内容、营销、定价）
   - 营销动作（活动、合作、PR）
   - 用户反馈（评论、社媒声音）
   - 战略动向（融资、并购、新业务）

2. 输出 markdown 报告，包含：
   - 本周概览（3-5 句话总结）
   - 竞品动态对比表（必须有 5 列以上）
   - 重点关注（哪个竞品动作最大 + 原因分析）
   - 我们的应对建议（至少 3 条，要可执行）
   - 下周关注点

3. 写作风格：
   - 客观中立，不要带情绪
   - 用数据说话，避免「显著」「大幅」这种形容词
   - 短句为主，每段不超过 3 行
   - 用 markdown 表格做对比

4. 文件名：competitor-weekly-report-YYYYMMDD.md

5. 直接输出，不要让我再追问
```

## 预期输出

```markdown
# 竞品对比周报 2026-06-30

## 本周概览
本周 3 家竞品均有动作，重点关注竞品 A 的 XX 新功能发布，
可能影响我们在 XX 方向的布局。竞品 B 启动了夏季营销活动，
用户反馈正面。竞品 C 暂时没有大动作。

## 竞品动态对比表

| 维度 | 竞品 A | 竞品 B | 竞品 C |
|------|-------|-------|-------|
| 本周更新 | XX 新功能上线 | 夏季营销活动 | 无重大更新 |
| 产品功能 | 增加了 XX 模块 | 优化 XX 流程 | — |
| 营销动作 | KOL 合作 50+ | 投放预算 +20% | — |
| 用户反馈 | 正面居多 | 等待评价 | — |
| 定价变化 | 无 | 限时 8 折 | — |
| 战略动向 | 传出融资消息 | 拓展海外市场 | — |

## 重点关注

### 竞品 A 的 XX 新功能
- **动作**：本周上线 XX 新功能
- **影响**：跟我们 Q3 路线图重合，可能分流用户
- **建议**：加快我们 XX 功能的研发节奏

## 我们的应对建议

1. **产品**：评估 XX 新功能的影响，决定是否调整路线图
2. **营销**：针对竞品 B 的夏季活动，提前准备应对话术
3. **用户**：主动联系 XX 类目用户，了解他们对竞品 A 新功能的看法

## 下周关注点

- 竞品 A 的 XX 功能上线数据
- 竞品 B 夏季活动效果
- 竞品 C 是否有 PR 计划
```

## 注意事项

### 🚨 信息准确

- 引用必须能溯源到原文
- 关键信息（产品功能、定价）必须自己确认
- 不要让 Codex 推测没在资料里出现的信息

### 🚨 客观中立

- 不要带情绪（不要写「竞品真垃圾」「这功能没用」）
- 客观描述事实，结论留给读者
- 涉及竞品负面信息要有理有据

### ⚠️ 常见坑

1. **资料太少**：只有 1-2 家竞品 → 对比意义不大
   - 解决：至少 3 家，最好 5 家
2. **资料过时**：用了 3 个月前的资料
   - 解决：每周更新一次
3. **格式混乱**：5 家竞品 5 种格式（PDF/截图/MD）
   - 解决：先做一次格式标准化
4. **维度不全**：只比了产品功能，没比营销
   - 解决：AGENTS.md 里固定必比维度
5. **没观点**：Codex 输出很中立但没用
   - 解决：在 prompt 里加「最后给出『我们的应对建议』」
