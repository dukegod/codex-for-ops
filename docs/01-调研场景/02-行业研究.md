# 行业研究

> 把一堆行业报告、新闻稿、专家观点截图丢给 Codex，让它 1 小时内出行业报告初稿。

## 🎬 场景故事

阿楠是增长组的运营，最近接了个大活：年底规划要写一份《2026 年中国银发经济市场趋势研究》，给 CEO 和董事会汇报。

她打开飞书搜了一下，团队共享盘里有：

- 8 份券商研报（PDF，艾瑞、QuestMobile、中商产业研究院等）
- 12 篇行业新闻稿（md/txt，从 36氪、虎嗅、第一财经导出）
- 5 张专家分享会的 PPT 截图
- 3 篇微信文章截图
- 2 份自家去年做的用户调研（docx）

按以往经验，她至少要花 **3-5 天** 通读 + 整理 + 写初稿。这次她用 Codex 做：**1 天出了 8000 字初稿**，剩下 2 天专门打磨观点和补数据。

这章教你怎么做。

## 🎯 你将学到

- 让 Codex 通读几十份资料、按主题归类、提取关键数据
- 让 Codex 按经典行业报告结构（宏观环境/竞争格局/用户画像/未来趋势）写初稿
- 让 Codex 在引用原文时标注来源，方便你二次核查

**预计耗时**：资料整理 2 小时，Codex 跑 30-60 分钟，人工修订 1-2 天。

## 📋 前置准备

- Codex 桌面端已登录
- 一个本地文件夹，结构建议：

> 💡 **小贴士**：在 `README.md` 里写一句话，比如：

```
# 2026 银发经济研究

目的：为公司 2026 年战略规划提供行业输入，重点关注 AI 在养老场景的应用。

关注地域：中国大陆。
关注时间窗口：2026-2028。
输出读者：CEO + 董事会（不懂技术的管理层）。
```

这一句话能让 Codex 输出时自动调整视角。

## 🚀 操作步骤

### Step 1：分批喂资料（重要）

**别一次性把所有 30 份资料全丢进去**。Codex 在一次性任务里能处理的信息有限，超出后会出现「读到了但没消化」的情况。

正确做法是**分四批**，对应行业报告的四个章节。

> 👀 **这里你会看到**：每批任务单独建一个 New Task，文件夹选对应子目录（如 `01-宏观环境/`）。

### Step 2：先用模板 1 跑「宏观环境」章节

粘贴模板 1 的 prompt，让 Codex 生成「宏观环境」章节初稿（约 800-1200 字）。

### Step 3：复制结果到主文档

Codex 输出后，复制到飞书文档 / Notion 的「行业研究-2026」主文档里。

### Step 4：依次跑其他三个章节

按同样方法跑「竞争格局」「用户画像」「未来趋势」，每跑完一个章节就粘贴到主文档。

### Step 5：让 Codex 写「执行摘要 + 结论建议」

最后单独建一个任务，把前四章的输出**整体复制粘贴给 Codex**（作为对话上下文），让它写 500 字的执行摘要和 300 字的下一步建议。

> 💡 **小贴士**：行业报告最值钱的两个部分是「执行摘要」和「结论建议」。这两块要单独建任务、单独跑，质量比中间章节高得多。

## 📝 完整 Prompt 模板

### 模板 1：单章节生成（以「宏观环境」为例）

**适用场景**：把 `01-宏观环境/` 文件夹交给 Codex，让它写这一章。

**完整 prompt**：

```
请阅读「01-宏观环境」文件夹里的所有资料，写一份行业研究报告的「宏观环境」章节初稿。

【读者画像】公司 CEO + 董事会成员，不是行业研究员，看不懂术语。

【章节要求】
1. 开头一段（150 字以内）说清「为什么 2026 年这个时点要看银发经济」（可用 1-2 个数据点开头）
2. 政策环境：列 3 条 2024-2026 年的关键政策，每条一句话解释影响
3. 经济环境：人口结构（老龄化率）、消费规模、可支配收入，各 1 个核心数据
4. 社会环境：城镇化、家庭结构变化（空巢老人比例）、代际观念差异，各 1 个观察
5. 技术环境：AI、物联网、可穿戴设备在养老场景的渗透，列 3 个代表性应用
6. 结尾一段（100 字）总结「这个宏观环境对我们公司意味着什么」

【写作要求】
- 每个数据点必须用【来源：文件名】标注，没标注的等于没数据
- 不要用「赋能」「抓手」「底层逻辑」这种空话
- 段落长度控制在 4-6 行，超了就拆段
- 总字数控制在 1500-2000 字

【特别注意】
- 如果资料里某个数据有矛盾（不同报告数字不同），请列出至少 2 个来源让我们判断
- 不要预测具体数字（比如「2026 年市场规模将达到 X 亿元」），除非资料里明确写了
```

**预期输出**：6 段结构化文字，每段包含具体数据和来源标注。

**调优提示**：
- 输出太学术 → 在 prompt 开头加「请用大白话写，把 CEO 当高中生讲」
- 数据点不够 → 在 prompt 里加「政策/经济/社会/技术每个角度至少 3 个数据点」
- 想再具体 → 加「政策环境那一段，请举 1 个我们能直接对接的政府项目」

### 模板 2：跨章节趋势综合

**适用场景**：4 个章节都写完后，让 Codex 做横向综合。

**完整 prompt**：

```
我刚才写完了行业研究的 4 个章节，下面是完整内容：

【宏观环境章节】
[粘贴第一章内容]

【竞争格局章节】
[粘贴第二章内容]

【用户画像章节】
[粘贴第三章内容]

【未来趋势章节】
[粘贴第四章内容]

请你基于以上内容，做两件事：

【任务 1：执行摘要 500 字】
- 第 1 段：3 句话说清「银发经济是什么 + 为什么 2026 重要 + 我们机会在哪」
- 第 2 段：列出 5 个最关键的判断（每个一句话）
- 第 3 段：列出 3 个最大风险

【任务 2：结论与建议 300 字】
- 给公司 CEO 的 3 条具体建议（每条要说「做什么」+「为什么」+「预期效果」）
- 不要写「加强布局」「提升能力」这种空话，要具体到「在 X 场景做 Y 产品」

【格式】
- 用 bullet，不要长段落
- 涉及数据时保留原文的【来源：xxx】标注
- 如果发现 4 个章节之间有数据矛盾，请单独列出来提醒我
```

**预期输出**：可粘贴进汇报文档开头的「执行摘要 + 建议」两段。

### 模板 3：补充信源

**适用场景**：发现某一块资料不够厚，让 Codex 推荐补充阅读。

**完整 prompt**：

```
我在写《2026 中国银发经济研究报告》，目前已经覆盖了宏观环境、竞争格局、用户画像、未来趋势 4 个章节。

【当前覆盖】
- 政策：已有 3 条政策
- 数据：已有市场规模、老龄化率、AI 渗透率
- 案例：已有 5 个头部企业案例
- 趋势：已有 AI + 养老的 3 个方向

【明显不足】
- 农村 vs 城市银发用户差异，几乎没有资料
- 60-70 岁「活力老人」与 80+ 岁「护理需求老人」的细分差异，不够清晰
- 海外（特别是日本）经验借鉴，没有资料
- 银发用户的支付意愿与价格敏感度，缺乏数据

请帮我推荐：
1. 还能补充哪些类型的数据/报告（具体到主题）
2. 推荐 5 个具体可查的来源（机构名 + 报告类型 + 关键词，不要求给链接）
3. 哪些主题我们应该在下一阶段专门做用户调研来补

不要写套话，要具体到「找什么、问谁、怎么问」。
```

**预期输出**：可执行的补充研究清单。

## ⚠️ 常见坑

- **坑 1：信源质量参差不齐，有些是软文** → 解决：在 prompt 里加一句「请优先引用政府机构、券商研报、头部咨询公司的资料，自媒体观点请标注【来源：自媒体】作为辅助参考」。
- **坑 2：Codex 编造数据点** → 解决：每个数据点必须【来源：文件名】。出稿后人工抽查 5 个数据。
- **坑 3：报告里出现敏感词被领导挑刺**（比如「赋能」「闭环」）→ 解决：用「敏感词清单」prompt 检查一遍：
  ```
  请检查下面这份报告，把所有「赋能/抓手/闭环/底层逻辑/打通/沉淀/链路」等空话列出来，并给出更具体的替代表达。
  ```
- **坑 4：英文报告翻译质量差** → 解决：英文报告单独跑任务，prompt 用英文写。中文 prompt 处理英文资料容易丢专业术语。
- **坑 5：4 个章节互相打架**（比如市场规模数字不一致） → 解决：用模板 2 的最后一行「如果 4 章有数据矛盾请列出」，最后阶段统一处理。
