# 竞品分析

> 把 3-5 家竞品的零散资料丢给 Codex，让它自动生成一张能直接放进汇报文档的对比表。

## 🎬 场景故事

小李是市场调研组的运营，每季度要给老板交一份竞品分析报告。上个月她刚做完一份关于「AI 笔记类产品」的竞品分析，过程是这样的：

周一早上收到老板邮件：「下周二前给我 Notion、飞书文档、Obsidian、Wolai、Coda 五家的产品对比，重点看 AI 能力、定价、目标用户。」

她打开电脑一看——桌面 5 个 PDF、3 个网页截图文件夹、2 篇行业新闻稿、1 个 Notion 导出页。手动整理至少要 2 天，还得熬夜加班。

后来她用 Codex 做了同样一件事：**2 小时搞定，老板还夸她这次报告比上次清晰**。

这章就把她的做法教给你。

## 🎯 你将学到

- 把分散的竞品资料统一交给 Codex，让它一次性提取信息
- 让 Codex 直接生成 Markdown 对比表（可直接复制到飞书文档 / Notion）
- 进阶玩法：让 Codex 自己抓网页、生成 PPT 大纲

**预计耗时**：第一次 1.5 小时（含准备资料），熟练后 30 分钟内出初稿。

## 📋 前置准备

- 一台装好 Codex 桌面端的电脑（macOS / Windows 均可）
- 已经登录 ChatGPT 账号（Plus 或 Pro 体验更佳）
- 一个整理好的本地文件夹，名字建议叫 `竞品分析-XXX-2026Q2` 之类，结构如下：

```
~/Desktop/竞品分析-AI笔记-2026Q2/
├── 产品资料/
│   ├── Notion-官网介绍.pdf
│   ├── 飞书文档-产品手册.pdf
│   ├── Obsidian-功能说明.pdf
│   ├── Wolai-帮助中心截图/
│   │   ├── 首页.png
│   │   ├── 定价页.png
│   │   └── AI功能介绍.png
│   └── Coda-发布会keynote.pdf
├── 新闻稿/
│   ├── 36氪-AI笔记产品评测.md
│   └── 虎嗅-飞书AI功能更新.md
└── 用户声音/
    └── 小红书-用户讨论-2026Q2.md
```

> 💡 **小贴士**：文件名尽量带品牌名，Codex 提取时能直接识别「哪段信息属于哪家公司」，避免张冠李戴。

## 🚀 操作步骤

### Step 1：新建任务并指向文件夹

打开 Codex 桌面端，点击左上角的 **「+ New Task」**。

> 👀 **这里你会看到**：
> 1. 顶部出现一个文件夹图标 🗂️（点击它选工作目录）
> 2. 中间是输入框，写着「Ask Codex to do anything...」
> 3. 底部有「Model」「Reasoning」「Security」三个下拉框

点击文件夹图标，选中刚才整理好的 `竞品分析-AI笔记-2026Q2` 文件夹。这样 Codex 能读取里面所有文件。

### Step 2：粘贴 prompt 让 Codex 提取信息

在输入框里粘贴下面「完整 Prompt 模板」里的内容，回车。

Codex 会开始逐个读取文件，并在右侧或下方实时输出思考过程。等 1-3 分钟（资料越多越久），它会给出结构化结果。

### Step 3：检查结果，追加追问

Codex 第一次输出可能漏掉某些维度。这时候**不要重新跑任务**，直接在对话里追问：

```
你刚才漏掉了「AI 能力的具体场景」和「目标用户的核心痛点」这两列。请补上，对 Notion、Obsidian、Coda 重点补全。
```

> 💡 **小贴士**：多轮对话比一次性 prompt 更稳。把一次大任务拆成「先提字段 → 再补内容 → 最后出表」三步走，质量高得多。

### Step 4：导出对比表

Codex 输出的 Markdown 表格可以直接复制：
- 粘贴到飞书文档 / Notion → 自动渲染成表格
- 复制到 Excel / 飞书表格 → 粘贴时选「保留源格式」
- 想做 PPT → 看下面「进阶技巧」

## 📝 完整 Prompt 模板

### 模板 1：基础对比表生成

**适用场景**：3-5 家竞品、资料比较齐全、第一次跑用这个。

**完整 prompt**：

```
请帮我做一份竞品对比分析报告。

【分析对象】
文件夹里有 5 家 AI 笔记类产品的资料：
- Notion（PDF: 产品介绍 + 官网截图）
- 飞书文档（PDF: 产品手册 + 新闻稿 2 篇）
- Obsidian（PDF: 功能说明）
- Wolai（截图 3 张）
- Coda（PDF: 发布会 keynote）

【对比维度（请严格按这个顺序）】
1. 公司背景（成立年份、定位、融资情况，如果有）
2. 核心功能（最多 5 个，每个一句话）
3. AI 能力（是否内置 AI、能做什么、是否有独特卖点）
4. 定价策略（免费版限制、付费版价格、企业版价格）
5. 目标用户（个人 / 团队 / 企业，核心痛点是什么）
6. 差异化亮点（这家最强的一点是什么）

【输出要求】
- 先用一段话（不超过 150 字）总结行业整体格局
- 然后输出 Markdown 对比表，列是 6 个维度，行是 5 家公司
- 表格下面用 bullet 列「最值得我方借鉴的 3 个点」和「需要警惕的 3 个点」
- 涉及具体数字（定价、用户数）的，请标注【来源：文件名】

如果某家资料里没找到某个字段，请写「资料未提及」，不要瞎编。
```

**预期输出**：一段行业总结 + Markdown 表格 + 借鉴/警惕清单。

**调优提示**：
- 输出太长 → 在 prompt 末尾加「每个字段控制在 30 字以内」
- 输出太抽象 → 加「请针对『AI 能力』这一列，每家举 1 个具体使用场景」
- 想再深一层 → 加「最后再写一段不超过 200 字的战略建议，给我们做产品决策参考」

### 模板 2：让 Codex 自己抓网页

**适用场景**：资料只有链接，没有 PDF；或者你想补充最新信息。

**完整 prompt**：

```
请帮我做一份关于【SaaS 客服系统】的竞品分析，目标是调研国内的 4 家：智齿、容联七陌、Udesk、网易七鱼。

【步骤】
1. 先用浏览器工具（如果可用）访问下面 4 个官网，抓取首页 + 定价页 + 功能页的文字内容：
   - https://www.zhichi.com
   - https://www.7moor.com
   - https://www.udesk.cn
   - https://qiyu.163.com

2. 然后访问「36氪」「虎嗅」「人人都是产品经理」这三个网站，搜索「2026 客服系统 评测」，抓取最近 3 个月内的 3 篇相关文章

3. 综合以上信息，按下面 6 个维度做对比表：
   - 核心功能
   - AI 能力（智能客服、机器人、工单自动化）
   - 定价
   - 客户案例（举 1-2 个代表客户）
   - 差异化卖点
   - 用户评价（从文章里提取正反两面）

4. 最后给一份 300 字以内的总结，指出哪家最值得我们深入对标

如果某个网站抓取失败，就跳过并在报告里说明，不要编内容。
```

**预期输出**：抓取过程说明 + 对比表 + 总结。

> ⚠️ **注意**：Codex 抓网页依赖浏览器插件或 MCP（Model Context Protocol，理解为「让 AI 调用外部工具的通道」）能力。如果你没装，先用模板 1 把本地资料跑通，再回来试这个。

### 模板 3：生成 PPT 大纲

**适用场景**：对比表要直接汇报，需要 PPT 骨架。

**完整 prompt**：

```
基于刚才生成的竞品对比表，请帮我做一份 PPT 大纲。

【场景】给公司管理层汇报，15 分钟时长，预计 12 页

【结构要求】
- 第 1 页：标题页（标题 + 副标题 + 日期）
- 第 2 页：分析背景和方法（一页说清「为什么做」「怎么做的」）
- 第 3-7 页：每家竞品一页（公司名 + 3 个核心要点 + 1 张产品截图占位）
- 第 8 页：横向对比表（精炼到 6 行 × 5 列）
- 第 9 页：行业趋势 3 个关键判断
- 第 10 页：我们能借鉴的 3 个点（具体到功能级别）
- 第 11 页：风险与挑战
- 第 12 页：下一步行动计划（5 项，每项一句话）

请只输出大纲（每页 3-5 个 bullet），不要展开写正文。我会基于这个大纲自己做 PPT。
```

**预期输出**：12 页 PPT 的 bullet 大纲，可直接复制到 PPT 备注栏。

## ⚠️ 常见坑

- **坑 1：资料太多一次性塞进去** → 解决：单次任务控制在 20 个文件以内。超过就拆成两轮跑，每轮跑一半资料，最后让 Codex 合并。
- **坑 2：不同公司资料混在一起**（比如同一份行业报告里提到了所有竞品） → 解决：文件名加前缀 `Notion-`、`飞书-`，并在 prompt 里说明「请按文件名归属，不要按内容出现顺序」。
- **坑 3：Codex 瞎编数据**（尤其定价、用户数） → 解决：prompt 里明确写「数字必须【来源：xxx】，没找到就写『资料未提及』」。出稿后人工抽查 3 个数字。
- **坑 4：截图里全是图片，Codex 读不到文字** → 解决：用 macOS 自带截图的「文本识别」（macOS 13+），或者先 OCR（Optical Character Recognition，把图片里的文字识别成可编辑文字的工具）再喂。
- **坑 5：对比维度太多，表格挤得难看** → 解决：拆成两张表。第一张「产品维度」（功能/AI/定价），第二张「市场维度」（用户/融资/口碑）。
