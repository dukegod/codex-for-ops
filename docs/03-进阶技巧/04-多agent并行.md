# 多 Agent 并行：同时跑多个调研任务

> 3 家竞品要分析、3 份周报要写——别排队，让 Codex 同时开 3 个窗口一起跑。

## 🎬 场景故事

小赵是行业研究组的负责人。每个季度他们要分析 10 家竞品，写 10 份分析报告。

以前他是这么做的：

1. 让小赵用 Codex 分析 A 竞品（30 分钟）
2. 再分析 B 竞品（30 分钟）
3. 再分析 C 竞品（30 分钟）
4. ……

3 家做完一个半小时过去了，效率太低。

后来他发现 Codex 桌面端支持**多 Agent 并行**——可以同时开多个任务，每个任务由一个独立的 Agent 在自己的「工作副本」（worktree）里跑，互不干扰。

他试了一次：同时开 3 个窗口跑 3 家竞品，30 分钟全部出结果。

效率提升 3 倍。

## 🎯 你将学到

- 理解 Codex 桌面端的多 Agent 并行机制（每个 Agent 独立工作副本）
- 把多个独立任务拆成并行任务的方法
- 同时运行 3-5 个 Agent 的完整操作流程
- 用「多 Agent 投票」做交叉校验的进阶技巧
- 并行太多电脑卡 / Agent 之间要共享数据怎么办

预计花 25 分钟。学会后你的「同一时间段里能完成的任务数」会直接翻倍。

## 📋 前置准备

- 已安装 Codex 桌面端 2026 年 2 月以后的版本
- 已会创建基础任务（看 [基础操作](../00-入门/04-基础操作.md)）
- 想清楚：**你今天要同时做的几件事**，哪些是真正独立的（不互相依赖结果）？
- 准备好每件事对应的资料文件夹
- 你的电脑配置建议：M1/M2/M3 Mac 或 16GB 内存以上的 Windows（并行越多越吃内存）

## 🚀 操作步骤

### Step 1：理解「并行」的前提

不是所有任务都适合并行。**只有互相独立的任务才适合并行**。

> ✅ 适合并行的：
> - 同时分析 3 家不同的竞品（互不依赖）
> - 同时生成周报和月报（不同时间范围）
> - 同时清洗 3 个不同的 Excel 文件
>
> ❌ 不适合并行的：
> - 「先分析 A 竞品 → 再用 A 的结果分析 B 竞品」（有依赖）
> - 「先写文案 → 再用文案生成图片」（有依赖）
> - 「同时改同一个文件的两个章节」（会冲突）

### Step 2：把任务拆成独立的小任务

比如「同时分析 3 家竞品」，拆完后长这样：

```
任务 1：分析竞品 A
  - 输入：~/Documents/竞品A/资料/
  - 输出：~/Documents/竞品分析/竞品A.md
  - Prompt：分析 A 的产品、定价、营销动作

任务 2：分析竞品 B
  - 输入：~/Documents/竞品B/资料/
  - 输出：~/Documents/竞品分析/竞品B.md
  - Prompt：分析 B 的产品、定价、营销动作

任务 3：分析竞品 C
  - 输入：~/Documents/竞品C/资料/
  - 输出：~/Documents/竞品分析/竞品C.md
  - Prompt：分析 C 的产品、定价、营销动作
```

每个任务的输入文件夹、输出位置、prompt 都不一样，但**结构相似**——这正是适合并行的特征。

### Step 3：在 Codex 里开多个并行任务

> 👀 **这里你会看到**：
> 1. Codex 桌面端左上角点「+ New Task」新建第一个任务
> 2. 在第一个任务的窗口**不要等它跑完**，直接点左上角「+ New Task」再建一个
> 3. 重复这个动作，直到开了 N 个任务窗口
>
> ```
> ┌─────────────────────────────────────────────┐
> │  Codex Desktop                              │
> ├─────────────────────────────────────────────┤
> │  [任务1: 竞品A]   [任务2: 竞品B]  [任务3: 竞品C] │  ← 顶部 Tab
> ├─────────────────────────────────────────────┤
> │  （当前选中的任务窗口）                       │
> │                                              │
> └─────────────────────────────────────────────┘
> ```

每个 Tab 是一个独立的 Agent。它们各自读各自的资料、各自跑各自的 prompt、结果各自存到各自的位置。

> 💡 **小贴士**：每个 Agent 跑在独立的「worktree」（工作副本）里——你可以理解为「同一个文件夹的多个平行宇宙」。Agent A 改了文件不会影响 Agent B 看到的版本，跑完才合并回主分支。所以即使两个 Agent 读同一份资料也不会冲突。

### Step 4：配置每个 Agent 的输入和 prompt

切到任务 1 的 Tab，输入：

- **输入文件夹**：`~/Documents/竞品A/资料/`
- **Prompt**：「请读取这个文件夹的所有资料，按下面的结构分析竞品 A……」

切到任务 2 的 Tab，配置竞品 B 的资料和 prompt。任务 3 同理。

> 👀 **这里你会看到**（每个 Tab 的配置独立）：
> ```
> 任务 1 Tab:
>   Folder: ~/Documents/竞品A/资料/
>   Prompt: 分析竞品 A 的产品、定价、营销动作
>
> 任务 2 Tab:
>   Folder: ~/Documents/竞品B/资料/
>   Prompt: 分析竞品 B 的产品、定价、营销动作
>
> 任务 3 Tab:
>   Folder: ~/Documents/竞品C/资料/
>   Prompt: 分析竞品 C 的产品、定价、营销动作
> ```

### Step 5：点「Run All」让所有 Agent 同时跑

配置好所有任务后，在 Codex 顶部的工具栏找到「▶ Run All」按钮（一个三角形 + 多条线的图标）。

点了之后，所有任务**同时开始跑**。每个 Agent 独立工作、独立输出。

你可以在 Codex 主界面看到所有 Agent 的进度：

> 👀 **这里你会看到**（进度视图）：
> ```
> ●  任务 1 (竞品A)   正在读资料 [▓▓▓░░░░░] 40%
> ●  任务 2 (竞品B)   正在生成报告 [▓▓▓▓▓▓░░░] 65%
> ●  任务 3 (竞品C)   已完成 ✓
> ```
> （绿色圆点 = 跑完，黄色圆点 = 正在跑，红色圆点 = 出错）

### Step 6：查看和合并结果

每个 Agent 跑完后，结果会按各自配置的输出位置保存。你可以：

- **逐个 Tab 查看**：切到每个 Tab 看完整结果
- **合并查看**：在 Codex 主界面点「Merge Results」，把多个 Agent 的输出合并到一个汇总文档
- **直接去文件夹看**：每个 Agent 输出的 Markdown 文件已经存到指定位置了

> 💡 **小贴士**：如果你的最终目的是生成「3 家竞品对比表」，可以再加一个汇总 Agent：让第 4 个 Agent 读取任务 1、2、3 的输出文件，生成对比表。这样 3 个并行分析 + 1 个汇总 = 完整的对比报告。

### Step 7：长任务交给远程，手机上看进度

有些并行任务会跑很久，比如 10 家竞品调研、半年用户反馈归因、历史活动素材重整。你不一定要一直守在电脑前。可以把任务交给远程环境继续跑，自己在手机上查看进度、审批关键动作、看最终差异。

适合远程跑的任务：

- 输入资料已经整理好，不需要你频繁补文件
- 任务会持续 30 分钟以上，电脑合盖或离线会影响进度
- 中间只需要你做少量审批，比如确认是否继续读取某个文件夹

不适合远程跑的任务：

- 需要操作你本机上的内部系统或桌面软件
- 资料只在本地电脑，远程环境没有权限访问
- 结果必须现场人工判断，不能等跑完再看

> 💡 **小贴士**：出门前先在 Codex 里把每个任务重命名，比如「Q3-竞品A」「Q3-竞品B」。手机上看进度时，任务名越清楚，越不容易点错审批。

## 📝 完整多 Agent 任务模板

### 模板 1：同时分析 3 家竞品

**适用场景**：一次季度竞品扫描，需要在 1 小时内拿到 3-5 家竞品的初步分析。

**任务拆分**：

```
任务 1：竞品 A 初步分析
  - 输入：~/Documents/竞品扫描/2026Q2/竞品A/
  - 输出：~/Documents/竞品扫描/2026Q2/输出/竞品A_分析.md
  - Prompt：
    读取本文件夹所有资料，生成竞品 A 的初步分析报告。
    包含：产品定位、目标用户、定价、近期营销动作、潜在威胁。
    字数控制在 500 字以内。

任务 2：竞品 B 初步分析
  - 输入：~/Documents/竞品扫描/2026Q2/竞品B/
  - 输出：~/Documents/竞品扫描/2026Q2/输出/竞品B_分析.md
  - Prompt：（同上，把 A 换成 B）

任务 3：竞品 C 初步分析
  - 输入：~/Documents/竞品扫描/2026Q2/竞品C/
  - 输出：~/Documents/竞品扫描/2026Q2/输出/竞品C_分析.md
  - Prompt：（同上，把 A 换成 C）

任务 4：汇总对比表（依赖任务 1-3，建议等前 3 个跑完后再开）
  - 输入：~/Documents/竞品扫描/2026Q2/输出/
  - 输出：~/Documents/竞品扫描/2026Q2/输出/竞品对比表.md
  - Prompt：
    读取 竞品A_分析.md、竞品B_分析.md、竞品C_分析.md，
    生成一张三家竞品的对比表，列包含：产品定位、目标用户、
    定价、近期营销动作、对我方威胁等级（高/中/低）。
```

**预期效果**：3 个初步分析 Agent 同时跑，约 20-30 分钟完成；汇总 Agent 再跑 5 分钟出对比表。总耗时 30-35 分钟（顺序做的话要 60-90 分钟）。

### 模板 2：同时生成周报和月报

**适用场景**：周一早上同时要交周报和月报。

**任务拆分**：

```
任务 1：周报
  - 输入：~/Documents/本周数据/
  - 输出：~/Documents/周报/周报_YYYY-MM-DD.md
  - Prompt：（用周报 Skill 的 prompt）

任务 2：月报
  - 输入：~/Documents/本月数据/
  - 输出：~/Documents/月报/月报_YYYY-MM.md
  - Prompt：（用月报 Skill 的 prompt）
```

两个任务数据范围不同、输出位置不同、风格不同，**完全独立**，非常适合并行。

### 模板 3：同时处理多个 Excel 清洗任务

**适用场景**：季度数据清洗，5 个 Excel 文件要分别处理。

**任务拆分**：

```
任务 1：清洗 销售数据_Q2.xlsx
  - 输入：~/Documents/原始数据/销售数据_Q2.xlsx
  - 输出：~/Documents/清洗后/销售_清洗后_Q2.xlsx
  - Prompt：见下方

任务 2：清洗 用户数据_Q2.xlsx
  - 输入：~/Documents/原始数据/用户数据_Q2.xlsx
  - 输出：~/Documents/清洗后/用户_清洗后_Q2.xlsx
  - Prompt：同上，字段名改一下

任务 3-5：（其他 3 个文件类似）
```

**清洗 Prompt 模板**：

```
读取 [文件名].xlsx，按以下规则清洗：

1. 删除完全空的行和列
2. 去除所有列名里的空格（如「用户 ID」改成「用户ID」）
3. 日期列统一成 YYYY-MM-DD 格式
4. 手机号列统一成 11 位不带 +86
5. 邮箱列统一小写
6. 数字列去掉千分位逗号

保存为 [清洗后文件名].xlsx，输出在 ~/Documents/清洗后/ 目录。
```

### 模板 4（进阶）：多 Agent 投票——交叉校验

**适用场景**：重要决策的文案 / 报告，想让多个 Agent 各自出方案，再对比挑最好的。

**任务拆分**：

```
任务 1：Agent A 生成方案 1
任务 2：Agent B 生成方案 2
任务 3：Agent C 生成方案 3
任务 4：汇总 Agent 评估三个方案，挑最优
```

每个 Agent 用**完全相同的输入和 prompt**，但因为 AI 生成有随机性，3 个 Agent 会给出略有不同的结果。汇总 Agent 读取 3 个结果，从「信息完整性」「表达清晰度」「与我方品牌调性匹配度」三个维度评分，挑出最优方案。

**适用场景举例**：

- 公司公众号头条推送（很重要，想看 3 个版本挑一个）
- 给老板的季度汇报（怕一个 Agent 想漏了，多跑几个交叉验证）
- 客户提案的核心文案（多版本对比）

> 💡 **小贴士**：投票模式**贵**——3 个 Agent 跑同一任务消耗 3 倍 token。只用在真正重要的、值得花 3 倍成本的场景。日常任务没必要。

## ⚠️ 常见坑

**坑 1：并行 5 个 Agent，电脑卡得不行，风扇狂转**
→ 解决：每个 Agent 都吃 CPU 和内存。建议**同时并行的 Agent 不超过 3-4 个**（MacBook Air）/ 5-6 个（MacBook Pro 或高配 Windows）。如果你电脑配置一般（M1 以下的 Mac 或 8GB 内存），建议每次只跑 2 个。如果真要并行很多个，分批跑：先跑 3 个，跑完再跑下一批 3 个。

**坑 2：两个 Agent 要共享同一份资料，结果互相覆盖**
→ 解决：让每个 Agent 读**自己独立的输入文件夹**。如果非要共享一份资料，把资料复制两份（`~/Documents/竞品A/资料/` 和 `~/Documents/竞品B/资料/`，内容一样但路径不同）。Codex 桌面端的 worktree 机制会保证每个 Agent 在独立的副本上工作，但如果两个 Agent 同时写入同一个输出文件，还是会冲突。

**坑 3：并行任务开太多，自己都看不过来哪个是哪个**
→ 解决：每个任务 Tab 重命名。点击 Tab 标题可以重命名，比如把「Task 1」改成「竞品 A - 产品分析」，「Task 2」改成「竞品 B - 产品分析」。Tab 重命名后一眼就能区分。

**坑 4：汇总 Agent 等不到前面 3 个跑完就开始了，输出的对比表是空的**
→ 解决：汇总 Agent **不要和前面的任务同时开**。等任务 1-3 都显示「已完成 ✓」后再点汇总 Agent 的「Run」。或者用 [自动化任务](02-自动化任务.md) 里的「任务依赖」功能（如果支持）——配置成「只有当任务 1-3 都完成时才触发任务 4」。

**坑 5：并行跑出来的几份结果质量参差不齐，不知道信哪个**
→ 解决：用「投票模式」时，汇总 Agent 的 prompt 要写清楚评分维度。比如：

```
请从以下 3 个方案中评估并选出最优：

方案 1：~/Documents/方案/方案1.md
方案 2：~/Documents/方案/方案2.md
方案 3：~/Documents/方案/方案3.md

评分维度（每项 1-10 分）：
1. 信息完整性（是否覆盖了所有要求的内容）
2. 数据准确性（数字是否与原始资料一致）
3. 表达清晰度（读者能否轻松看懂）
4. 与品牌调性匹配度（是否符合我方风格）

输出评分表 + 最终推荐方案。
```

**坑 6：把任务交给远程后，发现资料没带过去**
→ 解决：启动远程任务前先让 Codex 检查输入文件是否都在任务可访问的位置。不要把资料只放在桌面临时文件夹里；尽量放在项目资料夹、云盘同步目录，或者已经授权给 Codex 的文件夹。
