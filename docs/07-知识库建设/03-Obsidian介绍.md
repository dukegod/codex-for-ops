## 📋 一句话定义

**Obsidian = 本地 Markdown 文件 + 双向链接 + 插件生态的笔记软件**。

把文件存在你电脑本地，用 Markdown 写，用 `[[双向链接]]` 串联概念，用插件扩展功能。

## 🤔 Obsidian 不是什么

| ❌ 不是 | ✅ 是 |
|--------|------|
| 云端笔记（vs Notion / 语雀） | **本地笔记**，数据完全在你电脑上 |
| 在线协作（vs 飞书文档） | **单兵作战**工具，多人协作需要 Git |
| 全能数据库（vs Airtable） | **文档/笔记**工具，结构化数据不是强项 |
| 移动优先（vs Bear / 印象笔记） | 桌面体验更好，移动端只是补充 |
| 内置 AI（vs Notion AI） | **AI 需要外接**（这就是为啥要接 Codex） |

## 🆚 跟其他笔记工具的对比

| 维度 | Obsidian | Notion | 语雀 | 飞书文档 | 印象笔记 |
|------|---------|--------|------|---------|---------|
| **数据位置** | 本地 | 云端 | 云端 | 云端 | 云端 |
| **格式** | Markdown | 块结构 | Markdown | 块结构 | 富文本 |
| **双向链接** | ✅ 原生 | ❌ | ⚠️ 弱 | ❌ | ❌ |
| **图谱视图** | ✅ 原生 | ❌ | ❌ | ❌ | ❌ |
| **插件** | 1500+ | ❌ | ⚠️ 少 | ⚠️ 中等 | ❌ |
| **AI 集成** | 靠插件/外接 | ✅ 内置 | ⚠️ 弱 | ✅ 内置 | ⚠️ 弱 |
| **离线使用** | ✅ 完全 | ❌ | ❌ | ❌ | ⚠️ 部分 |
| **数据导出** | ✅ 纯文件 | ⚠️ 复杂 | ⚠️ 复杂 | ⚠️ 复杂 | ⚠️ 复杂 |
| **价格** | 免费（个人） | 免费/付费 | 免费/付费 | 企业版付费 | 免费/付费 |

**核心差异**：Obsidian 的「本地 + Markdown + 双向链接」是独一份的。这三点决定了它特别适合做知识库。

## 🎯 5 个核心功能（够你上手用）

### 功能 1：双向链接 `[[]]`

这是 Obsidian 的灵魂功能。

```markdown
我最近在学 [[GPT-5]]，它跟 [[Claude 4]] 是竞品关系。
[[推理能力]] 是大模型的关键指标。
```

`[[]]` 包起来的就是链接。点链接跳转到对应页面，**反向链接**自动显示「哪些页面链到了我」。

**对知识库的价值**：你的概念会自然地互相连接，半年后能发现「哦原来 A 和 B 是相关的」。

### 功能 2：图谱视图

左下角点 **Graph View**，会显示你所有笔记的关系图：

```
   [GPT-5] ←→ [Claude 4]
       ↕           ↕
   [推理能力] ←→ [多模态]
       ↕
   [训练方法]
```

节点 = 笔记，边 = 双向链接。

**对知识库的价值**：可视化让你「看到」知识结构，不只是看单篇文档。

### 功能 3：本地 Markdown 文件

Obsidian 库就是一堆 `.md` 文件，存在你电脑的文件夹里。

```
my-vault/
├── 笔记1.md
├── 笔记2.md
├── 子文件夹/
│   └── 笔记3.md
└── 图片附件.png
```

**优势**：
- 任何文本编辑器都能打开（VSCode、Typora、记事本）
- 任何版本控制都能管理（Git）
- 数据完全属于你，迁移零成本
- 可以用脚本批量处理（Codex 直接读整个文件夹）

### 功能 4：插件系统

1500+ 社区插件，覆盖各种场景：

| 场景 | 推荐插件 |
|------|--------|
| 模板 | Templater |
| 看板 | Kanban |
| 数据可视化 | Charts |
| 反向链接增强 | Various Complements |
| AI | Smart Connections / Copilot / Claudian |
| 同步 | Remotely Save（用云盘同步） |
| 任务管理 | Tasks |
| 日历 | Calendar |

### 功能 5：嵌入和引用

可以在笔记里嵌入其他笔记的内容：

```markdown
![[GPT-5#推理能力]]
```

会直接把 GPT-5 笔记里的「推理能力」章节渲染到这里。

也可以引用但不嵌入：

```markdown
[[GPT-5#推理能力|看 GPT-5 的推理能力]]
```

## 🎯 谁适合用 Obsidian

### ✅ 强烈推荐

- **写作者 / 研究者**：需要长期积累、跨主题引用
- **学生 / 学者**：学习、复习、做笔记、做研究
- **产品经理 / 运营**：沉淀方法论、案例库、SOP
- **程序员**：写技术笔记、API 文档、项目记录
- **个人知识管理爱好者**：想打造自己的「第二大脑」

### 🤔 看情况

- **团队协作**：Obsidian 不擅长，团队还是用 Notion / 飞书
- **纯移动办公**：Obsidian 移动端能用，但体验一般
- **对插件无感**：只用基础功能的话，Obsidian 跟其他工具差别不大

### ❌ 不推荐

- **纯新人**：连 Markdown 都不想学的——先用 Notion
- **完全不需要双向链接**：比如只做日程管理——用 Todoist / 滴答清单
- **需要实时多人协作**：直接用飞书文档 / 腾讯文档

## 🤔 在用 Obsidian 的成本

### 一次性成本

- **学习 Markdown**：1-2 小时
- **理解双向链接**：30 分钟
- **配置插件**：按需，每个 15-30 分钟

### 持续成本

- **每周 review**：30-60 分钟
- **每月整理归档**：1-2 小时
- **每季度清理**：半天

### 不做的话的成本

- 笔记越积越多，找不到 → 放弃 → 重新建 → 又放弃（恶性循环）
- 跨主题找不到关联 → 知识变成孤岛
- 切换工具成本高（数据迁移困难）

## 🎯 我推荐的 Obsidian 起步方案

如果你刚装好 Obsidian，按这个顺序配置：

### 必备配置（30 分钟）

1. **建 6 个核心文件夹**（基于你自己已经用的结构）：
   ```
   inbox/         # 临时收集
   todo/          # 待办事项
   journal/       # 日记/复盘
   concepts/      # 概念/知识
   archive/       # 归档
   templates/     # 模板
   ```

2. **装 3 个核心插件**：
   - **Templater**：自动套模板
   - **Various Complements**：反向链接增强
   - **Calendar**：日记视图

3. **写 3 个基础模板**：
   - `daily-note.md`（日记模板）
   - `concept.md`（概念笔记模板）
   - `meeting.md`（会议记录模板）

### 进阶配置（按需）

- **DATAVIEW** / **Bases**：数据库视图（你已经用了 .base）
- **Claudian / Copilot**：AI 集成（[下一章讲](04-obsidian与codex的整合.md)）
- **Excalidraw**：画图
- **Kanban**：看板视图
- **Tasks**：任务管理

### 怎么开始写第一篇

1. 打开 Obsidian
2. 新建笔记：`Ctrl/Cmd + N`
3. 命名：`2026-06-30-第一次用Obsidian.md`（用日期开头，便于排序）
4. 内容：随便写点啥
5. 加一个 `[[]]` 链接：试试 `[[Obsidian]]`
6. 看图谱：点左下角 Graph View，看你的第一个节点

**5 分钟跑通**。

## ⚠️ Obsidian 的几个常见误区

### ❌ 误区 1：装太多插件

新人最容易踩的坑——装 50 个插件，每个用 2 次就忘了。

**建议**：先装 3 个核心插件，3 个月后再加新的。

### ❌ 误区 2：追求完美结构

花 3 天设计文件夹结构，比写笔记的时间还长。

**建议**：先随便建，跑 3 个月后再调整。结构是演化的，不是设计的。

### ❌ 误区 3：囤积但不消化

收藏 100 篇文章，每篇都加进 Obsidian，但从不打开第二次。

**建议**：用「3 个 R」原则：
- **Read**：读
- **Refine**：消化（写自己的笔记）
- **Reuse**：复用（用到工作里）

### ❌ 误区 4：把 Obsidian 当成「任务管理」

Obsidian 适合做「知识沉淀」，任务管理用专门的工具（Todoist、滴答清单）。

**建议**：Obsidian 装 Tasks 插件做轻量任务管理，复杂的用专业工具。
