# 知识库建设：LLM + Wiki + Obsidian + Codex

> 把碎片信息变成持续积累、互相链接的个人知识库

## 🎯 这章在讲什么

这是本手册里最"长期主义"的一章——前面讲的是怎么用 Codex 干活，**这章讲怎么用 Codex 把干的活沉淀成你自己的知识资产**。

整个流程：

```
碎片信息（微信、网页、笔记、对话、读的书）
   ↓ 让 Codex 消化
结构化 Wiki（实体、主题、摘要）
   ↓ 用 Obsidian 承载
可双向链接的个人知识库
   ↓ 持续维护 + Codex 协作
不断进化的"第二大脑"
```

## 🔑 几个关键认知

1. **知识库 ≠ 笔记软件**：笔记软件是工具，知识库是「你思考的载体」
2. **AI + Wiki 的核心是"被编译一次"**：Karpathy 的原话——知识被结构化整理一次，后续每次查询就不用从原始信息重新推导
3. **Obsidian 是载体，不是限制**：选什么笔记软件不重要，「wiki 化、双向链接、持续维护」的思路才重要
4. **Codex 是消化引擎**：把碎片信息变成结构化 Wiki 的过程，靠 Codex 自动化
5. **个人知识库 = 第二大脑**：不是堆资料，是让信息能反复调用、能跨主题关联、能产生新洞察

## ⚠️ 别期待太多

- ❌ **不会一夜成为大牛** —— 知识库的价值在「3-5 年」这个尺度，不在「1 个月」
- ❌ **不会自动产出洞察** —— 工具再强，思考还是你的事
- ❌ **不会替代学习** —— 知识库是「已经学过的」沉淀，不是「学习本身」
- ✅ **会让你的工作产出可复用** —— 这是最大的价值
