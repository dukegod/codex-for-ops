# 权限与审批：Codex 能干什么、不能干什么

> 这一章讲 Codex 桌面端的权限模型。三种安全等级怎么选、文件夹怎么授权、授权错了怎么撤销。

## 🎬 场景故事

小李第一次用 Codex 桌面端，看到一个提示「请选择授权文件夹」，他想都没想就点了「整个用户目录」。然后他让 Codex「帮我整理桌面」。

Codex 认真执行了——它把桌面上的所有 .docx 文件移动到了一个叫「organized」的文件夹里，包括：

- 还没写完的述职报告
- 跟律师的保密邮件草稿
- 刚下载的、还没改名的客户合同 PDF

小李下班前发现文件全乱了，但 Codex 已经完成任务，且无法撤销。

**这不是 Codex 的问题，是小李给了它太大的权限。**

## 🎯 你将学到

- Codex 桌面端的三种安全等级，分别适合什么场景
- 怎么只授权特定文件夹，而不是整个用户目录
- 怎么撤销已经给出的授权
- 团队成员之间的权限怎么管

## 📋 前置准备

- 已经装好 Codex 桌面端并登录
- 知道这次任务要用哪些资料

## 🚨 Codex 桌面端的权限模型

Codex 桌面端有三层权限，理解清楚才能用得安心。

### 第一层：文件夹授权

告诉 Codex「这次任务你可以读 / 写哪些文件夹」。这是最重要的一层。

### 第二层：命令审批

Codex 在你的电脑上跑命令（比如 `rm`、`mv`、`pip install`）时，要不要你点确认。

### 第三层：Action 确认

Codex 的每一步动作（读文件、改文件、跑命令）要不要单独弹窗让你确认。

这三层通过「安全等级」统一控制。

---

## 🚨 三种安全等级

### 「建议模式」（Suggest Mode）

Codex 把要做的事写成方案给你看，**不会真的执行**。你需要每条都点「批准」它才会动。

| 维度 | 表现 |
|------|------|
| 文件读取 | 每读一个文件都要你点 |
| 文件修改 | 只给 diff（差异对比），不直接改 |
| 命令执行 | 只列出「准备跑 xxx 命令」，不会真跑 |
| 适用人群 | **运营新手必选** |
| 适合任务 | 第一次用、不熟悉的资料、敏感数据 |

### 「自动编辑」（Auto-Edit Mode）

Codex 自动读文件、自动改文件，**但跑命令需要你确认**。这是日常推荐模式。

| 维度 | 表现 |
|------|------|
| 文件读取 | 自动 |
| 文件修改 | 自动改，但保留可撤销（worktree 机制） |
| 命令执行 | 弹窗让你点确认 |
| 适用人群 | **日常主力模式** |
| 适合任务 | 资料整理、Excel 处理、批量改名 |

### 「全自动」（Full-Auto Mode）

Codex 在一个**隔离沙箱**（可以理解为「一个临时小黑屋」）里全自动跑，不打扰你。

| 维度 | 表现 |
|------|------|
| 文件读取 | 自动 |
| 文件修改 | 自动写回主目录 |
| 命令执行 | 自动 |
| 适用场景 | **只在信任场景用**，比如处理公开资料 |
| 不适合 | 任何含敏感数据的任务 |

> 🚨 **红线**：第一次接触一个项目，永远从 Suggest 模式开始。等你熟悉 Codex 的行为再切到 Auto-Edit。

## 🚀 操作步骤：切换安全等级

### Step 1：打开设置

点击 Codex 桌面端右上角的齿轮图标（⚙），进入「Settings」（设置）。

### Step 2：找到「Approval Mode」

在「Safety」分类下找到「Approval Mode」（审批模式），三个选项对应上面三个等级。

### Step 3：选择等级

- 第一次用 → 选 Suggest
- 日常主力 → 选 Auto-Edit
- 跑公开数据 + 自动化任务 → 选 Full-Auto

### Step 4：保存

设置会自动保存，下次启动还是这个模式。

---

## 🚀 操作步骤：只授权特定文件夹

### Step 1：新建任务时选择文件夹

新建任务（+ New Task），系统会弹出文件夹选择器。**不要选「整个用户目录」**。

### Step 2：选任务相关的那个文件夹

比如这次任务是「整理本周的用户反馈」，就只授权 `~/Documents/用户反馈-2026Q2/` 这一个文件夹。

### Step 3：开始任务

Codex 只能访问这个文件夹里的内容，读不到你的桌面、下载、文档其他位置。

---

## 🚀 操作步骤：撤销文件夹授权

### Step 1：打开设置 → Privacy（隐私）

进入 Settings → Privacy，你会看到「Authorized Folders」（已授权文件夹）列表。

### Step 2：找到要撤销的文件夹

每个文件夹右边有一个「Revoke」（撤销）按钮。

### Step 3：撤销

点了之后 Codex 就不能再访问那个文件夹了。已经处理过的文件不会受影响。

## 📝 模板：查询当前授权

**适用场景**：你忘了自己授权过哪些文件夹。

**完整 prompt**：

```
请告诉我：
1. 当前你被授权访问的所有文件夹
2. 每个文件夹的授权时间
3. 你是否还保留着这些文件夹里的文件索引（如果保留，请说明保留多久）
```

**预期输出**：一张清单，列出所有授权文件夹 + 时间。

---

## 📝 模板：撤销文件夹授权

**适用场景**：你想撤销某个文件夹的授权。

**完整 prompt**：

```
请撤销我对 [文件夹路径] 的授权。
例如：撤销我对 /Users/zhangsan/Documents/客户数据/ 的授权。
```

**预期输出**：Codex 调用撤销接口，告诉你「已撤销」。

---

## 📝 模板：查看 Codex 跑过的所有命令

**适用场景**：你想审查 Codex 这次任务都跑了什么命令。

**完整 prompt**：

```
请列出这次任务里你执行过的所有 shell 命令（shell 命令就是你在终端里敲的命令），按时间顺序，并标注每个命令的目的。
```

**预期输出**：一份命令清单 + 用途说明。

## 🔐 进阶：团队权限管理

如果公司用的是 Codex 团队版（Team Plan），管理员可以做这些事：

- **统一配置安全等级**：强制所有成员用 Suggest 模式
- **审计日志**（Audit Log）：查看所有成员跑过的任务
- **数据保留策略**：设置聊天记录的保留天数
- **SSO 登录**：用公司账号体系登录，不让员工用私人账号

找公司 IT 或管理员确认你们团队有没有开这些功能。

## ⚠️ 常见坑

- **坑 1**：把根目录（Mac 是 `/`，Windows 是 `C:\`）授权给 Codex → 解决：永远只授权具体的子文件夹
- **坑 2**：Full-Auto 模式下没看 diff（Codex 准备改的内容对比）就批准 → 解决：Full-Auto 也保留 diff 确认弹窗，别急着点
- **坑 3**：任务结束后忘了撤销授权 → 解决：跑完任务顺手在 Settings 里撤销
- **坑 4**：授权了一个文件夹，里面又有指向其他文件夹的「快捷方式」（Mac 叫替身，Windows 叫快捷方式） → 解决：快捷方式可能让 Codex 跨文件夹访问，要先解除
- **坑 5**：把别人发来的 zip 解压后直接授权整个解压目录，里面可能有意外文件 → 解决：解压后先看一下再授权
