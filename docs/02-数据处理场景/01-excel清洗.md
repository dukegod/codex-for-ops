# Excel 清洗与转换

> 把运营每天都在头疼的「脏 Excel」，一键变成能直接分析的干净表格。

## 🎬 场景故事

小李是市场活动组的运营，每周一会收到一份「上周活动报名数据」Excel。

她打开一看——

- 一共 7 个 sheet，有的 sheet 里只有标题没数据
- 标题行混着「姓名 / Name」「手机 / Phone Number」「报名时间」中英文
- 有的「手机号」列里有人写成 `138 0013 8000`，有人写成 `+86-13800138000`
- 日期格式五花八门：`2026/6/28`、`2026-06-28`、`2026年6月28日`
- 顶部还留了两行空行，A 列整列空白
- 还有合并单元格：「付费用户」这四个字跨了 A、B 两列

以前她得手动调半小时，现在她把 Excel 扔给 Codex，**两分钟拿到一份干净的版本**。

## 🎯 你将学到

- 怎么让 Codex 自动识别并清洗 Excel 里的脏数据
- 一份完整的「Excel 清洗 prompt 模板」，下次直接改改就能用
- 进阶玩法：让 Codex 写一段 Python 脚本，**批量**处理几十个 Excel

时间：第一次 15 分钟，熟练后每次 2-3 分钟。

## 📋 前置准备

- ✅ 已安装 Codex 桌面端并登录（见[安装与登录](../00-入门/02-安装与登录.md)）
- ✅ 一个本地文件夹，专门放「待清洗 Excel」（建议放在桌面，比如 `~/Desktop/待清洗/`）
- ✅ 一个本地文件夹，专门放「清洗后 Excel」（比如 `~/Desktop/已清洗/`）
- ✅ 安全模式建议选 **Workspace（受信任工作区）**，首次跑清洗时给 Codex 只读权限，看完输出再决定要不要让它写文件

## 🚀 操作步骤

### Step 1：把待清洗的 Excel 放进指定文件夹

在桌面建一个 `待清洗` 文件夹，把这周要处理的 Excel 全丢进去。

> 👀 **这里你会看到**：
>
> ```
> ~/Desktop/待清洗/
> ├── 活动报名_本周.xlsx        ← 主文件
> ├── 销售周报_汇总.xlsx        ← 顺带清洗
> └── 用户反馈_6月.xlsx
> ```

### Step 2：打开 Codex，指向这个文件夹

打开 Codex 桌面端 → 点击左上角「+ New Task」→ 在输入框左侧能看到文件夹选择器，选 `~/Desktop/待清洗/`。

> 👀 **这里你会看到**：
>
> ```
> ┌─────────────────────────────────┐
> │  Codex Desktop                  │
> ├─────────────────────────────────┤
> │  [+ New Task]    [≡]  [⚙]      │
> ├─────────────────────────────────┤
> │  📁 ~/Desktop/待清洗/   [换]   │
> ├─────────────────────────────────┤
> │  Ask Codex to do anything...   │
> │                          [⏎]  │
> └─────────────────────────────────┘
> ```

### Step 3：先用一句中文让 Codex 看看数据长啥样

在输入框粘贴下面这段 prompt，然后回车：

```
请扫描当前文件夹里所有的 .xlsx 文件，告诉我每个文件有几个 sheet、表头长什么样、有哪些明显的脏数据问题（空行/空列/合并单元格/日期格式不统一/手机号格式混乱）。只输出问题清单，不要改文件。
```

Codex 会返回一份「体检报告」，比如：

> 活动报名_本周.xlsx 发现 6 个问题：1) 第 1-2 行是空行；2) A 列整列空白；3) 表头中英文混杂；4) 报名时间列存在 3 种日期格式……

### Step 4：根据体检报告，让 Codex 写清洗规则 + 清洗代码

复制下面这段完整的 prompt 模板，粘贴到 Codex 输入框，回车：

```
基于你刚才的体检报告，对当前文件夹的所有 .xlsx 文件执行以下清洗规则，清洗结果输出到 ~/Desktop/已清洗/ 文件夹（保持原文件名，后缀改为 _cleaned.xlsx）：

【清洗规则】
1. 删除完全空白的行和列
2. 拆分所有合并单元格，把原值填到每个被合并的格子
3. 删除顶部非数据的标题/说明行（连续空行 + 第一行非表头内容）
4. 表头标准化：保留英文为主的表头（如果中英文都有，取英文；如果只有中文，保留中文）
5. 统一日期格式为 YYYY-MM-DD（识别 2026/6/28、2026年6月28日、06-28-2026 等）
6. 统一手机号格式：去掉空格、+86、横线，保留 11 位纯数字；如果长度不是 11 位，标红并在原列右边新增「手机号_校验」列写「格式异常」
7. 数字列去掉单位（如「元」「件」「%」），单独建一列「单位」
8. 在每个输出文件的 A 列后面新增一列「数据来源」，值等于原文件名

【输出要求】
- 每个清洗后的文件单独保存
- 同时在 ~/Desktop/已清洗/ 下生成一个 _清洗日志.txt，记录每个文件改了什么
- 不要覆盖原文件
- 如果遇到无法自动判断的字段，先跳过并在日志里标记「需人工确认」

【运行方式】
请用 Python 写脚本（推荐用 pandas + openpyxl），在沙箱里直接运行。
```

Codex 会自动在沙箱里跑 Python 脚本，跑完后会告诉你「清洗完成，输出了 3 个文件 + 1 个日志」。

### Step 5：人工抽查 1-2 个文件

打开 `~/Desktop/已清洗/活动报名_本周_cleaned.xlsx`，随机抽 20 行对一下原表。重点看：

- 日期是不是真的统一了
- 手机号校验列有没有漏网的
- 有没有把正常数据当成空行给删了

> 💡 **小贴士**：第一次跑建议把输出文件发给业务方核对一遍，再固定成周/月度流程。

## 📝 完整 Prompt 模板

### 模板 A：通用 Excel 清洗

**适用场景**：任何来源的 Excel，格式混乱，需要清洗成可分析的版本。

**完整 prompt**：

```
请扫描当前文件夹里所有 .xlsx 和 .xls 文件，对每个文件执行清洗。

【清洗规则】
1. 删除完全空白的行和列
2. 拆分所有合并单元格，把原值复制到每个被合并的格子
3. 删除顶部非数据的标题/说明行
4. 表头标准化为英文（PascalCase 风格，如 RegisterDate）
5. 统一日期格式为 YYYY-MM-DD
6. 统一手机号格式：去掉空格、+86、横线，保留 11 位纯数字；异常的在右边新增「PhoneStatus」列标记
7. 数字列去掉单位，新建「Unit」列保留单位文字

【输出】
- 清洗结果保存到 ~/Desktop/已清洗/ 文件夹，文件名加 _cleaned 后缀
- 同时生成 _清洗日志.txt，记录每个文件的改动
- 用 Python（pandas + openpyxl）在沙箱里跑
- 不要修改原文件

【遇到无法判断的】
跳过并在日志里写「需人工确认：xxx」。
```

**预期输出**：N 个 `_cleaned.xlsx` + 1 个 `_清洗日志.txt`。

**调优提示**：
- 如果日志里「需人工确认」太多 → 在 prompt 里补充业务规则，比如「报名时间在晚上 23:00 之后的判定为凌晨时段」
- 如果日期识别有偏差 → 指定列名，比如「报名时间这一列按 YYYY-MM-DD 输出，不要带时分秒」
- 如果文件超大 → 见下文「常见坑」

### 模板 B：批量清洗（一个文件夹 50+ Excel）

**适用场景**：每周/每月批量处理几十个结构相似的 Excel。

**完整 prompt**：

```
~/Desktop/批量清洗/ 文件夹里有约 50 个结构相同的销售周报 Excel，请用 Python 写一个批量处理脚本：

1. 遍历该文件夹下所有 .xlsx
2. 对每个文件应用模板 A 的清洗规则
3. 清洗结果输出到 ~/Desktop/批量清洗_输出/
4. 所有文件的清洗结果合并成一份 汇总.xlsx（追加一个 Sheet「来源」记录每行来自哪个文件）
5. 输出 _清洗日志.txt
6. 脚本保存到 ~/Desktop/批量清洗_脚本.py，下次复用

【注意】
- 大文件（>10万行）请分块读取，不要一次性加载内存
- 如果某个文件清洗失败，不要中断整体流程，记录到日志继续下一个
```

## ⚠️ 常见坑

### 坑 1：Excel 文件太大（10 万行以上），脚本直接卡死

**原因**：pandas 默认一次性把整个 sheet 读进内存（RAM），Excel 一上 10 万行就吃 1-2 GB 内存。

**解决**：在 prompt 里加一句「大文件请用 openpyxl 的 read_only 模式逐行读取，或者用 chunksize 分块处理」，并指定「只保留必要列，不要全表读」。

### 坑 2：中文编码乱码

**症状**：打开清洗后的文件，列名变成 `？？？` 或者 `å¼ ä¸­æ–‡`。

**解决**：让 Codex 在脚本里加 `encoding='utf-8-sig'`（带 BOM 的 UTF-8），Excel 打开就不会乱码。或者在 prompt 里直接写「请保证输出文件在 Excel 2016+ 打开不乱码」。

### 坑 3：Codex 误删了表头行

**原因**：如果表头下面是连续几行空行，Codex 可能把表头当作「说明行」也删了。

**解决**：在 prompt 里明确说「第一行非空的行视为表头，从下一行开始是数据」，或者「表头包含关键词 xxx（如『姓名』『手机号』），找到包含这些关键词的行作为表头」。

### 坑 4：手机号脱敏要求

**场景**：客户数据不能明文给 Codex 看，但又要清洗。

**解决**：先在本地用 Excel 把手机号中间 4 位改成 `****`，再喂给 Codex；或者用 Codex 工作区的脱敏 Skills（见[进阶技巧篇的 Skills 章](../03-进阶技巧/01-skills.md)）。

### 坑 5：清洗后数字精度丢失

**症状**：原来是 `1234567890.123456`，清洗后变成 `1234567890.12`。

**解决**：在 prompt 里加一句「数值列保留原始精度，不要四舍五入；如果是小数，请在 Excel 里设成『数值』格式而不是『文本』格式」。
