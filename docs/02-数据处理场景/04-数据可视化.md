# 数据可视化

> 让 Codex 把分析结果一键变成能放进周报、PPT、对外文章的配图。

## 🎬 场景故事

小周刚做完本周活跃用户分析（见[上一章](03-表格分析.md)），现在要把关键发现做成配图塞进周报。

她面对 3 个常见场景：

1. **趋势**：DAU 这一周是怎么变化的？要画折线图
2. **对比**：哪个渠道贡献最大？要画柱状图
3. **占比**：付费用户里新客老客比例？要画……等等，要不要画饼图？（**先别急，往下看**）

她以前是这么做的：把数据粘到 Excel → 选数据 → 插入图表 → 调颜色 → 改字号 → 调图例位置 → 截图 → 粘贴……一折腾半小时。

现在她把数据 CSV 扔给 Codex，**3 分钟拿到一份可编辑的 SVG**，拖进 Figma 还能继续改。

## 🎯 你将学到

- 怎么让 Codex 选**对的图表类型**（趋势用折线、对比用柱状、占比慎用饼图）
- 怎么生成 PNG（直接用）、SVG（可编辑）、PDF（印刷质量）3 种格式
- 中文字体、配色、图例这些「看起来不专业」的坑怎么避开
- 5 类最常见图表的完整 prompt 模板

时间：第一次 20 分钟，熟练后每次 3-5 分钟。

## 📋 前置准备

- ✅ 已安装 Codex 桌面端
- ✅ 一份数据文件（CSV 或 Excel）
- ✅ 输出文件夹（比如 `~/Desktop/图表输出/`）
- ✅ 如果要生成中文图表，**确保系统装了中文字体**（macOS 自带 PingFang，Windows 自带微软雅黑）

## 🚀 操作步骤

### Step 1：明确你想表达什么

在动手之前先问自己：**这张图是要让人看出趋势、对比、占比，还是相关性？**

| 想表达什么 | 推荐图表 |
|-----------|---------|
| 时间趋势（DAU 怎么变） | 折线图 |
| 类别对比（哪个渠道卖得多） | 柱状图 |
| 部分占整体（占比、构成） | 100% 堆叠柱图（**饼图不推荐**） |
| 两个变量关系（广告花费 vs 销售额） | 散点图 |
| 多维度对比（按天 × 渠道） | 热力图 |
| 单一数值 | KPI 数字卡片（不用图） |

> ⚠️ **关于饼图**：除非真的只有 2-3 个分类并且差距悬殊，否则不要用饼图。**饼图的视觉精度极差**——人眼很难判断扇形是 23% 还是 27%。用横向柱图或堆叠柱图代替。

### Step 2：把数据 CSV 放进工作文件夹

```
~/Desktop/图表任务/
├── data.csv
└── 字段说明.md（可选，但推荐）
```

### Step 3：把图表需求完整告诉 Codex

粘贴下面这个 prompt 模板：

```
基于 data.csv 画一张折线图，输出 PNG 到 ~/Desktop/图表输出/。

【图表规格】
- 类型：折线图（趋势）
- X 轴：日期（2026-06-23 ~ 2026-06-29）
- Y 轴：DAU（去重用户数）
- 数据：每天一个点
- 标题：「本周 DAU 趋势（2026-06-23 ~ 2026-06-29）」
- 副标题：「环比上周上涨 8.5%」

【样式要求】
- 尺寸：宽 1200px × 高 600px（适合 PPT 16:9）
- 中文字体：macOS 用 PingFang SC，Windows 用 Microsoft YaHei（用 matplotlib 的 rcParams 设置）
- 配色：主色 #4A90E2（蓝），背景白色，网格线浅灰
- 数据点标注：在每个数据点上方标数值（整数，不要小数）
- 不要图例（只有一条线）

【输出】
- PNG（直接给 PPT 用）
- 同时输出 SVG 版本（可编辑，给设计用）
- 用 matplotlib + seaborn 在沙箱里跑
- 如果中文字体显示成方框，请检查并修复字体配置
```

Codex 会自动跑脚本，输出两张图。

### Step 4：检查图能不能看

打开 PNG 检查：

- ✅ 中文是不是正常显示（不是方框、不是乱码）
- ✅ 数字标注有没有和数据点对齐
- ✅ Y 轴有没有从 0 开始（折线图最好从 0 起，否则会夸大变化）
- ✅ 标题、副标题、轴标签有没有歧义

## 📝 完整 Prompt 模板

### 模板 A：折线图（趋势）

**适用场景**：展示时间序列数据的变化趋势。

**完整 prompt**：

```
基于 data.csv 画一张折线图：

【数据】
- X 轴：日期
- Y 轴：[指标名]
- 多条线：[如果有，按需列出，比如「本周 DAU」「上周 DAU」]

【图表规格】
- 尺寸：1200×600
- 标题：[主标题]
- 副标题：[关键发现，用一句话]
- 中文字体：PingFang SC（macOS）/ Microsoft YaHei（Windows）
- 配色：[主色 1] / [主色 2]，用 ColorBrewer Set2 色板
- 数据点：标注数值
- 网格：水平网格，浅灰

【输出 PNG + SVG 到 ~/Desktop/图表输出/】
```

### 模板 B：柱状图（对比）

**适用场景**：比较不同类别的数值。

**完整 prompt**：

```
基于 data.csv 画一张横向柱状图（条形图）：

【数据】
- Y 轴：类别名（比如渠道名、商品名）
- X 轴：数值（比如销售额、用户数）
- 排序：按数值降序

【图表规格】
- 尺寸：1000×800
- 标题：[主标题]
- 在每根柱子末端标注数值
- 中文字体：PingFang SC
- 配色：单色渐变（深到浅），按数值大小
- 网格：垂直网格，去掉水平网格

【输出 PNG + SVG】
```

> 💡 **小贴士**：类别超过 10 个时，**只画 TOP 10，其他合并为「其他」**，否则图会很挤。

### 模板 C：堆叠柱状图 / 100% 堆叠柱图（占比）

**适用场景**：展示占比随时间变化，或对比不同总体的内部结构。

**完整 prompt**：

```
基于 data.csv 画一张 100% 堆叠柱状图：

【数据】
- X 轴：日期（或类别）
- Y 轴：占比（0-100%）
- 堆叠维度：[多个分类，比如「新客/老客」「渠道 A/渠道 B/渠道 C」】

【图表规格】
- 尺寸：1200×600
- 标题：[主标题]
- 图例：放在右上角
- 配色：ColorBrewer Set2 或 Pastel1（柔和的色板）
- 在柱子内部标注占比（百分比）

【输出 PNG + SVG】
```

### 模板 D：散点图（相关性）

**适用场景**：看两个变量有没有相关性。

**完整 prompt**：

```
基于 data.csv 画一张散点图：

【数据】
- X 轴：[变量 1，比如「广告花费（元）」]
- Y 轴：[变量 2，比如「当天销售额（元）」]
- 每个点代表一天的数据

【图表规格】
- 尺寸：1000×1000
- 标题：[主标题]
- 添加趋势线（线性回归），显示相关系数 R²
- 中文字体：PingFang SC
- 配色：单色（蓝），点的透明度 0.6（避免重叠遮挡）
- 网格：淡灰

【输出 PNG + SVG】
```

### 模板 E：热力图（多维度对比）

**适用场景**：同时看两个维度（比如「按天 × 渠道」活跃度）。

**完整 prompt**：

```
基于 data.csv 画一张热力图：

【数据】
- 行：[维度 1，比如「星期几」]
- 列：[维度 2，比如「渠道」]
- 颜色深浅：[指标值，比如「DAU」]

【图表规格】
- 尺寸：1200×600
- 标题：[主标题]
- 配色：YlOrRd（黄→橙→红）或者 Viridis
- 在每个格子内标注数值
- 颜色条：放在右侧，标注「低 → 高」
- 中文字体：PingFang SC

【输出 PNG + SVG】
```

## 📐 进阶技巧

### 技巧 1：让 Codex 直接生成可编辑的 SVG

PNG 不能改，SVG 可以拖到 Figma 里继续调整。在 prompt 里加一句「**同时输出 SVG 版本**」，并要求：

- 文字用 `<text>` 元素（不要转成路径）
- 形状用基本图元（`<rect>`、`<circle>`、`<path>`）
- 配色用 hex 值（不要用 rgba）

### 技巧 2：让 Codex 配中文标题和副标题

图表的「标题」和「副标题」是传达洞察的关键。在 prompt 里加：

- 主标题：「本周 DAU 趋势（2026-06-23 ~ 2026-06-29）」
- 副标题：「环比上周上涨 8.5%，主要由新用户拉新活动贡献」
- 数据来源：「数据来源：内部 BI 系统」

这 3 行放在图下方，比单独在 PPT 里加文字更专业。

### 技巧 3：让 Codex 生成多张小图组合

如果要做 dashboard，用 prompt 让 Codex 一次生成 4-6 张子图（趋势 + 对比 + 占比 + 异常点），输出在同一张图里（matplotlib 的 subplots）。

```
画一张 2×2 的子图布局，包含：
- 左上：本周 DAU 趋势折线图
- 右上：各渠道新增用户柱状图
- 左下：新客老客占比堆叠柱图
- 右下：付费转化漏斗（用横向柱图模拟）
每张子图独立标题，整体大标题在最上方。
```

### 技巧 4：让 Codex 用 seaborn 主题

在 prompt 里加「用 seaborn 的 whitegrid 主题，配色用 Set2」，出来的图比 matplotlib 默认好看 2 个档次。

## ⚠️ 常见坑

### 坑 1：中文字体显示成方框

**症状**：图里所有中文都是 □□□。

**原因**：matplotlib 默认不带中文字体。

**解决**：在 prompt 里加：

```
请在脚本里设置中文字体：
import matplotlib
matplotlib.rcParams['font.sans-serif'] = ['PingFang SC', 'Microsoft YaHei', 'SimHei']
matplotlib.rcParams['axes.unicode_minus'] = False
如果还是显示方框，请列出系统已安装的中文字体，选一个能用的。
```

### 坑 2：图例太长被截断

**症状**：右侧图例只显示了一半，另一半被画布裁掉了。

**解决**：在 prompt 里加「图例放在图下方（`loc='upper center', bbox_to_anchor=(0.5, -0.15), ncol=3`）」，或者「图例字号调小到 10」。

### 坑 3：Y 轴不从 0 开始，夸大变化

**症状**：本周和上周 DAU 实际涨了 5%，但图里看着像涨了 50%。

**解决**：折线图和柱状图的 Y 轴**必须从 0 开始**。在 prompt 里明确「Y 轴下限设为 0」。

### 坑 4：配色辣眼睛

**症状**：默认的红绿蓝配色，PPT 里显得很业余。

**解决**：在 prompt 里指定配色（hex 值），或者让 Codex 用 ColorBrewer 的 Set2、Pastel1、Tableau10 等专业色板。

### 坑 5：导出 PNG 模糊

**原因**：matplotlib 默认 dpi=100，放到 PPT 上放大就糊了。

**解决**：在 prompt 里加「保存 PNG 时设 `dpi=200`，或者用 `bbox_inches='tight'` 裁掉多余白边」。

### 坑 6：饼图用了不合适的场景

**症状**：8 个分类的饼图，每块都差不多大，看不出谁重要。

**解决**：换成横向柱状图，或者只保留 TOP 5 + 「其他」合并项。
