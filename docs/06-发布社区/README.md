# 发布社区：从整合资源到发布到小红书

> 把你自己的方法、模板、Skill 分享给更多人

## 🎯 这章在讲什么

把你在运营/调研/数据处理中积累的好方法、好模板，**整合成结构化的 Skill，通过 Codex + xiaohongshu-mcp 发布到小红书**。

整个流程是：

```
你的资料/笔记/灵感
   ↓ 整合（Codex 帮你整理）
结构化方法论
   ↓ 打包（Codex 创建 Skill）
可复用的 Skill
   ↓ 发布（xiaohongshu-mcp + Codex）
小红书笔记 + 嵌入的 RED Skill 组件
```

## ⚠️ 重要前提

发布到小红书需要满足：

1. **小红书账号**：注册满 6 个月 + 粉丝 ≥ 1000（开通 RED Skill 功能的要求）
2. **实名认证**：必须完成
3. **账号健康**：无违规记录
4. **本机环境**：Mac / Windows / Linux + 稳定的网络
5. **基础投入**：约 30-60 分钟首次配置

如果你还没达到粉丝门槛，可以先做**前 3 章**（资源整合 + 创建 Skill），发布动作等粉丝达标后再做。Skill 可以先存在本地。
