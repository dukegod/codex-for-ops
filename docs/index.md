## 关于这份手册

**Codex 运营手册**是一份**面向运营团队**的 Codex 桌面端实战手册。

Codex 桌面端（Codex Desktop）是 OpenAI 推出的 AI 智能体桌面应用，原本是给程序员用的，但它的**「读资料、跑分析、整理文档」能力，对运营团队同样强大**。这份手册把它的运营用法从入门讲到进阶。

适合谁看：

- ✅ 调研岗位（竞品分析、行业研究、资料整理）
- ✅ 数据岗位（Excel 处理、批量任务、表格分析）
- ✅ 增长岗位（用户研究、报告生成）
- ✅ 想把工作方法论沉淀成 Skill 发布到社区的同事

## 阅读建议

| 你是谁 | 推荐阅读顺序 |
|--------|------------|
| **完全没用过 Codex** | 入门篇 1-5 → 调研/数据场景篇（按需） |
| **已经会用 ChatGPT** | 入门篇 1、3、5 → 调研/数据场景篇（按需） → 进阶篇 |
| **想深入挖高级功能** | 全部章节，按顺序 |
| **只想解决问题** | 用顶部搜索跳到对应章节 |
