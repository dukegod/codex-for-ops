Codex 桌面端（Codex Desktop）是 OpenAI 推出的 AI 智能体桌面应用，原本是给程序员用的，但它的**「读资料、跑分析、整理文档」能力，对运营团队同样强大**。这本手册专门写给运营团队：

- ✅ 调研岗位（竞品分析、行业研究、资料整理）
- ✅ 数据岗位（Excel 处理、批量任务、表格分析）
- ✅ 增长岗位（用户研究、报告生成）

## 🚀 5 分钟快速上手

如果你是第一次接触 Codex，按这个顺序操作：

1. **下载安装**：[下载 Codex 桌面端](https://openai.com/codex/)（macOS / Windows）
2. **登录账号**：用你的 ChatGPT 账号登录（Plus/Pro 体验最佳）
3. **新建任务**：点击左上角「+ New Task」，输入你想做的事
4. **选择文件夹**：告诉 Codex 你这次任务的资料放在哪个文件夹
5. **等结果**：Codex 会读你的资料、整理、生成结果给你审

具体步骤看 [安装与登录](docs/00-入门/02-安装与登录.md)。

## 🎯 几个真实案例

**Case 1：竞品分析**
> 把 3 家竞品的产品介绍 PDF 放在一个文件夹里，让 Codex 提取关键信息生成对比表。

**Case 2：周报生成**
> 把本周的用户反馈 Excel + 数据周报喂给 Codex，让它生成周报初稿。

**Case 3：会议纪要**
> 把飞书妙记导出的会议文本丢给 Codex，让它整理成结构化纪要 + 待办事项。

**Case 4：批量重命名**
> 让 Codex 把一个文件夹里的 200 张活动照片按"日期-活动名-序号"批量重命名。

更多案例看 [调研场景篇](docs/01-调研场景/) 和 [数据处理场景篇](docs/02-数据处理场景/)。

## ⚠️ 重要提醒

- **不要把客户隐私数据、未公开的财务数据、内部敏感文档直接喂给 Codex**。详见 [数据安全](docs/04-安全红线/01-数据安全.md)。
- **永远先小范围测试再大规模使用**。Codex 很强大但也会犯错。
- **结果要人工审核**。Codex 是工具，最终责任在人。
